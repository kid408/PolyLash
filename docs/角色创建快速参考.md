## 🔧 技术要点

### PlayerBase自动功能（改进后）

✅ **自动创建SkillManager**
- 检测CSV配置
- 自动加载技能
- 无需手动代码

✅ **自动处理输入**
- Q键：蓄力技能
- E键：瞬发技能
- LMB：左键技能
- F键：大招

✅ **向后兼容**
- 现有角色不受影响
- 子类可覆盖行为

### 角色脚本模板（最小版本）

```gdscript
extends PlayerBase
class_name PlayerTempest

var skill_manager: SkillManager

func _ready() -> void:
	super._ready()
	skill_manager = SkillManager.new(self)
	add_child(skill_manager)
	skill_manager.load_skills_from_config("tempest")

func _handle_input(delta: float) -> void:
	move_dir = Input.get_vector("move_left", "move_right", "move_up", "move_down")
	if can_move():
		position += move_dir * speed * delta
	
	if not skill_manager:
		return
	
	if Input.is_action_just_pressed("skill_f"):
		if ultimate_skill:
			ultimate_skill.try_activate()
	elif Input.is_action_just_pressed("skill_e"):
		skill_manager.execute_skill("e")
	elif Input.is_action_pressed("skill_q"):
		skill_manager.charge_skill("q", delta)
	elif Input.is_action_just_released("skill_q"):
		skill_manager.release_skill("q")
	elif Input.is_action_just_pressed("click_left"):
		skill_manager.execute_skill("lmb")
```

## 🐛 常见问题速查

### 问题：技能不工作

**检查清单**：
- [ ] player_skill_bindings.csv 是否配置？
- [ ] 技能ID是否正确？
- [ ] skill_params.csv 是否有对应配置？
- [ ] 控制台是否有错误信息？

**控制台输出**：
```
✅ 正常：[PlayerBase] ✅ 自动创建技能管理器成功: tempest (已加载 3 个技能)
❌ 错误：[SkillManager] 错误: 无法加载技能脚本 skill_xxx.gd
```

### 问题：角色属性不对

**检查清单**：
- [ ] player_config.csv 是否配置？
- [ ] player_id 是否匹配？
- [ ] CSV格式是否正确（逗号分隔）？
- [ ] 数值类型是否正确（整数/浮点数）？

### 问题：精灵图片不显示

**检查清单**：
- [ ] player_visual.csv 是否配置？
- [ ] sprite_path 路径是否正确？
- [ ] 图片文件是否存在？
- [ ] 图片是否已导入Godot？
