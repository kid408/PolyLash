# 技能系统 (Skill System)

## 系统概述

PolyLash 的技能系统是游戏的核心玩法机制，玩家通过**画线**来释放技能，形成独特的战术体验。技能系统包含三个主要按键：

- **Q键**：画线技能（蓄力型，子弹时间）
- **E键**：瞬发技能（快速释放）
- **F键**：大招技能（终极技能，暂未实现）

---

## 一、Q键技能 - 画线系统

### 1.1 核心机制

Q键技能是游戏最核心的玩法，玩家按住Q键进入**规划模式**（子弹时间），然后按住鼠标左键在屏幕上画线，松开Q键后执行技能。

#### 规划模式流程

```
1. 按住Q键 → 进入规划模式（时间减速至0.1倍）
2. 按住鼠标左键 → 开始画线（从鼠标位置开始）
3. 移动鼠标 → 实时绘制路径（每10像素记录一个点）
4. 松开鼠标左键 → 停止画线
5. 右键点击 → 清除所有路径并返还能量
6. 松开Q键 → 退出规划模式，执行技能
```

#### 能量消耗机制

Q技能采用**动态递增能量消耗**：

- **基础阶段**：每10像素消耗固定能量（如0.4点）
- **递增阶段**：超过阈值距离（如1800像素）后，能量消耗开始递增
- **递增公式**：`消耗 = 基础消耗 × (1 + 超出距离 × 递增系数)`

```gdscript
# 示例：屠夫技能参数
energy_per_10px = 0.4              # 每10像素消耗0.4能量
energy_threshold_distance = 1800   # 阈值距离1800像素
energy_scale_multiplier = 0.001    # 递增系数0.001
```


### 1.2 闭合检测机制

画线过程中，系统会实时检测路径是否形成**闭合空间**，闭合与非闭合状态会触发完全不同的效果。

#### 闭合判定条件

1. **线段交叉**：任意两条不相邻的线段相交
2. **距离闭合**：终点接近起点或路径中的其他点（容错距离60像素）

#### 闭合容错提升（羁绊加成）

- **几何学家羁绊**：每级增加15像素容错距离
- 示例：基础60像素 + 几何学家Lv.2 = 90像素容错

#### 视觉反馈

- **未闭合**：白色线条
- **已闭合**：红色线条（实时变色）
- **能量不足**：灰色线条
- **超过阈值**：白色→橙色渐变

---

### 1.3 闭合 vs 非闭合效果

不同角色的Q技能在闭合和非闭合状态下有完全不同的表现：

#### 示例1：屠夫（Butcher）

| 状态 | 效果描述 |
|------|---------|
| **非闭合** | 沿路径释放锯条，对接触敌人造成持续伤害并击退 |
| **闭合** | 在闭合区域内放置肉桩，用链条连接形成绞杀区域，捕获并拉扯敌人 |

#### 示例2：火焰（Pyro）

| 状态 | 效果描述 |
|------|---------|
| **非闭合** | 沿路径创建火墙，阻挡敌人并造成接触伤害（20伤害/秒） |
| **闭合** | 闭合区域内创建火海，持续对区域内敌人造成伤害（40伤害/秒） |

#### 示例3：疾风（Wind）

| 状态 | 效果描述 |
|------|---------|
| **非闭合** | 沿路径创建风墙，将敌人吸向风墙中心并造成伤害 |
| **闭合** | 闭合区域内创建暴风区，持续将敌人拉向中心（更强吸力） |

## 二、E键技能 - 瞬发技能

### 2.1 核心机制

E键技能是**瞬发型技能**，按下E键立即释放，无需蓄力或画线。

#### 执行流程

```
1. 按下E键 → 检查冷却和能量
2. 消耗能量 → 立即执行技能效果
3. 播放音效 → 通用E技能音效（skill_e_instant）
4. 启动冷却 → 进入冷却状态
```

#### 能量消耗

- E技能消耗**固定能量**（在 `player_config.csv` 中配置）
- 示例：屠夫E技能消耗50能量

---

根据功能，E技能可分为以下几类：

#### 类型1：范围伤害/控制

| 角色 | 技能名 | 效果 | 能量消耗 | 冷却 |

| **火焰** | 火焰环 | 在角色周围产生火焰冲击波，击退附近敌人 | 35 | 8秒 |
| **疾风** | 暴风眼 | 在角色位置创建暴风眼，吸引并伤害附近敌人 | 8 | - |
| **狱警** | 盾击 | 在角色前方扇形范围内击退敌人 | 35 | 8秒 |

#### 类型2：Buff/增益

| 角色 | 技能名 | 效果 | 能量消耗 | 冷却 |

### 2.4 E技能实现示例

以通用冲刺技能（skill_dash）为例：

```gdscript
extends SkillBase
class_name SkillDash

# 技能参数（从CSV加载）
var dash_distance: float = 400.0    # 冲刺距离
var dash_speed: float = 2000.0      # 冲刺速度
var dash_damage: int = 20           # 冲刺伤害
var dash_knockback: float = 2.0     # 击退力度

# 执行技能
func execute() -> void:
    # 检查条件
    if not can_execute():
        return
    
    # 消耗能量
    if not consume_energy():
        return
    
    # 计算冲刺目标位置
    var mouse_pos = skill_owner.get_global_mouse_position()
    var dir = (mouse_pos - skill_owner.global_position).normalized()
    dash_target = skill_owner.global_position + dir * dash_distance
    
    # 开始冲刺
    _start_dash()
    
    # 启动冷却
    start_cooldown()
```

## 四、技能管理器（SkillManager）

### 4.1 架构设计

技能管理器负责管理角色的所有技能，采用**槽位系统**：

```gdscript
var skill_slots: Dictionary = {
    "q": null,      # Q键技能
    "e": null,      # E键技能
    "lmb": null,    # 左键技能（通常是冲刺）
    "rmb": null     # 右键技能（预留）
}
```

### 4.2 技能加载流程

```
1. 读取 player_skill_bindings.csv → 获取角色技能绑定
2. 根据 skill_id 加载技能脚本 → res://scenes/skills/players/{skill_id}.gd
3. 创建技能实例 → 继承自 SkillBase 或 SkillDrawingBase
4. 从 skill_params_wide.csv 加载参数 → 设置技能属性
5. 添加到场景树 → 保存到对应槽位
```

#### 示例：屠夫技能绑定

`config/player/player_skill_bindings.csv`：
```csv
player_id,slot_q,slot_e,slot_lmb,slot_rmb
butcher,skill_saw_path,skill_meat_stake,skill_dash,
```

### 4.3 技能执行接口

```gdscript
# 瞬发技能（E键、左键）
skill_manager.execute_skill("e")

# 蓄力技能（Q键）
skill_manager.charge_skill("q", delta)    # 持续按住
skill_manager.release_skill("q")          # 松开按键
```

### 4.4 技能基类（SkillBase）

所有技能继承自 `SkillBase`，提供通用功能：

```gdscript
class_name SkillBase

# 基础属性
var skill_owner: Node2D        # 技能所有者
var skill_id: String           # 技能ID
var energy_cost: float         # 能量消耗
var cooldown_time: float       # 冷却时间

# 运行时状态
var is_on_cooldown: bool       # 是否冷却中
var is_charging: bool          # 是否蓄力中
var is_executing: bool         # 是否执行中

# 虚函数接口（子类实现）
func execute() -> void         # 执行技能
func charge(delta: float)      # 蓄力技能
func release() -> void         # 释放技能
```

### 4.5 画线技能基类（SkillDrawingBase）

Q键画线技能继承自 `SkillDrawingBase`，提供画线通用功能：

```gdscript
class_name SkillDrawingBase extends SkillBase

# 画线参数
var energy_per_10px: float              # 每10像素能量消耗
var energy_threshold_distance: float    # 能量递增阈值
var energy_scale_multiplier: float      # 能量递增系数
var close_threshold: float              # 闭合判定阈值
var base_line_duration: float           # 线条持续时间

# 运行时状态
var is_planning: bool                   # 是否规划模式
var is_drawing: bool                    # 是否正在画线
var path_points: Array[Vector2]         # 路径点列表
var has_closure: bool                   # 是否闭合

# 虚函数接口（子类实现）
func _spawn_line_effect(start, end)    # 生成线段效果（非闭合）
func _spawn_area_effect(polygon)       # 生成区域效果（闭合）
func _get_line_color() -> Color        # 获取线条颜色
func _get_closure_color() -> Color     # 获取闭合颜色
```

## 九、常见问题

### Q1：为什么Q技能画线时能量消耗越来越快？

**答**：这是设计的动态递增机制。超过阈值距离（如1800像素）后，能量消耗会按照递增系数逐渐增加，防止玩家画出过长的路径。

### Q2：如何提高闭合容错距离？

**答**：装备几何学家羁绊，每级增加15像素容错距离。

### Q3：为什么有时候画线闭合了但没有触发闭合效果？

**答**：检查以下几点：
1. 路径点数是否足够（至少3个点）
2. 是否真的形成了闭合（线段交叉或距离闭合）
3. 是否在松开Q键时才进行最终闭合检测

### Q4：E技能冷却时间可以缩短吗？

**答**：可以，通过以下方式：
1. 装备弹药羁绊（冷却时间-15%/-30%）
2. 使用铁匠E技能（重置Q技能冷却）
3. 装备特定装备（如"冷却缩减"属性）

### Q5：如何查看角色的技能配置？

**答**：
1. 打开 `config/player/player_skill_bindings.csv` 查看技能绑定
2. 打开 `config/player/skill_params_wide.csv` 查看技能参数
3. 打开 `config/player/player_config.csv` 查看角色基础属性

## 十、总结

PolyLash 的技能系统通过**画线机制**创造了独特的战术深度：

1. **Q键画线**：闭合与非闭合产生完全不同的效果
2. **E键瞬发**：快速释放，提供爆发或辅助
3. **羁绊集成**：不同羁绊显著改变技能表现
4. **动态能量**：防止过度画线，增加策略性
5. **配置驱动**：所有参数可通过CSV调整，无需改代码

这套系统为32个角色提供了丰富的玩法变化，同时保持了统一的操作逻辑。
