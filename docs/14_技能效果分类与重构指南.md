# PolyLash 技能效果分类与重构指南

## 文档概述

本文档详细分类了 PolyLash 游戏中所有技能的效果类型，用于后续重构技能系统。通过分析 32 个角色的 Q/E/F 技能实现，提取公共效果模式，为重构提供清晰的架构指导。

**文档完整性**：
- ✅ 32个角色的Q技能（画线系统）完整列表
- ✅ 32个角色的E技能（瞬发技能）完整列表
- ✅ 32个角色的F技能（大招系统）完整列表
- ✅ 所有技能的效果类型和参数详解
- ✅ 技能实现模式和重构建议
- ✅ 大招系统架构和特殊实现详解

## 一、技能效果分类体系

### 1.1 核心效果类型

根据代码分析，技能效果可分为以下核心类型：

#### 🔥 伤害类效果
- **直接伤害**：瞬间造成固定伤害
- **持续伤害（DOT）**：每隔一定时间造成伤害
- **范围伤害（AOE）**：对区域内所有敌人造成伤害
- **处决伤害**：对特定条件敌人造成额外伤害

#### ❄️ 控制类效果
- **冰冻（Freeze）**：完全禁止移动
- **减速（Slow）**：降低移动速度
- **眩晕（Stun）**：短暂禁止移动和攻击
- **定身**：禁止移动但可攻击
- **击退（Knockback）**：强制位移

#### 🌪️ 物理效果
- **吸附（Pull）**：将敌人拉向目标点/线
- **推开（Push）**：将敌人推离目标点
- **墙体阻挡**：创建物理障碍物
- **碰撞伤害**：接触时造成伤害

#### 💊 增益/减益效果
- **移速加成**：提升移动速度
- **护盾/护甲**：增加防御
- **治疗**：恢复生命值
- **伤害放大**：增加受到的伤害
- **易伤标记**：标记敌人增加伤害


#### 🎯 特殊机制
- **召唤物**：生成友方单位
- **陷阱/地雷**：延迟触发的伤害
- **传送/冲刺**：快速位移
- **资源生成**：生成金币/能量
- **状态叠加**：多层效果累积

## 二、Q 技能效果分类（画线系统）

### 2.1 画线技能架构

所有 Q 技能继承自 `SkillDrawingBase` 或 `SkillBase`，核心机制：
- **规划模式**：子弹时间 + 鼠标划线
- **能量消耗**：每 10 像素消耗能量，超过阈值后递增
- **闭合检测**：线段交叉或距离闭合
- **双状态效果**：未闭合（线条效果）+ 闭合（区域效果）

### 2.2 火焰系（烈焰者）

**技能名称**：`SkillFirePath` - 火线与火海

**未闭合效果**：
- 效果类型：持续伤害线条
- 实现方式：`SkillEffectManager.create_line_effect()`
- 核心参数：
  - `fire_line_damage = 20`：每 0.5 秒伤害
  - `fire_line_duration = 5.0`：持续时间
  - `fire_line_width = 24.0`：线条宽度

**闭合效果**：
- 效果类型：持续伤害区域（火海）
- 实现方式：`SkillEffectManager.create_area_effect()`
- 核心参数：
  - `fire_sea_damage = 40`：每 0.3 秒伤害
  - `fire_sea_duration = 5.0`：持续时间
- 特殊机制：
  - **P0-1 羁绊**：闭合图形伤害加成
  - **P2-1 羁绊**：二次爆炸（0.3 秒后触发，伤害 50%，范围 1.5 倍）
  - **P2-4 羁绊**：诅咒叠加（每秒 1 层，每层 3 伤害）
  - **P3-1 羁绊**：连锁反应（区域外敌人受到 30% 伤害）
  - **P3-2 羁绊**：永久牢笼（转换为物理墙体，最多 5 个，持续 15 秒）
  - **P3-3 羁绊**：小图形暴击（面积 < 15000 时伤害 x2）


### 2.3 冰霜系（冰河）

**技能名称**：`SkillGlacierQ` - 冰墙与冰冻区域

**未闭合效果**：
- 效果类型：物理墙体（StaticBody2D）
- 实现方式：`SkillEffectManager.create_wall_effect()`
- 核心参数：
  - `wall_duration = 5.0`：墙体持续时间
  - `wall_width = 16.0`：墙体宽度
  - `block_enemies = true`：阻挡敌人
  - `block_bullets = true`：阻挡子弹

**闭合效果**：
- 效果类型：冰冻 Debuff 区域
- 实现方式：`SkillEffectManager.create_debuff_zone()`
- 核心参数：
  - `freeze_duration = 2.0`：冰冻持续时间
  - `debuff_type = "freeze"`：冰冻状态

### 2.4 风暴系（御风者）

**技能名称**：`SkillWindPath` - 风墙与暴风区域

**未闭合效果**：
- 效果类型：吸附线条 + 持续伤害
- 实现方式：`SkillEffectManager.create_line_effect()`
- 核心参数：
  - `wind_wall_damage = 15`：每 0.5 秒伤害
  - `wind_wall_pull_force = 350.0`：吸附力度
  - `wind_wall_duration = 3.0`：持续时间
  - `pull_to_line = true`：吸附到线段
  - `pull_interval = 0.05`：物理更新频率

**闭合效果**：
- 效果类型：吸附区域 + 持续伤害
- 实现方式：`SkillEffectManager.create_area_effect()`
- 核心参数：

### 2.5 地雷系（工兵）

**技能名称**：`SkillMinePath` - 布雷路径

**未闭合效果**：
- 效果类型：沿线布雷（稀疏）

## 三、E 技能效果分类（瞬发技能）

所有 E 技能继承自 `SkillBase`，核心机制：
- **瞬发释放**：按 E 键立即触发
- **能量消耗**：固定能量消耗
- **冷却时间**：技能冷却机制
- **效果类型**：范围伤害、控制、召唤、增益等

### 3.2 火焰新星（烈焰者）

**技能名称**：`SkillFireNova` - 烈焰新星

**效果类型**：范围持续伤害

**实现方式**：
- 创建 Area2D + CircleShape2D
- Timer 定时伤害 tick
- Polygon2D 视觉效果

**核心参数**：
- `fire_nova_radius = 140.0`：爆炸半径
- `fire_nova_damage = 35`：每 0.5 秒伤害
- `fire_nova_duration = 3.0`：持续时间

**特殊机制**：
- 缩放动画：从 0 到 1 的 Back 缓动

### 3.3 冰爆（冰河）

**技能名称**：`SkillGlacierE` - 冰爆

**效果类型**：范围击退 + 护盾 + 冰冻

- 遍历范围内敌人

- 护甲：`skill_owner.armor = min(armor + shield_amount, max_armor)`

## 四、效果实现模式总结

### 4.1 线条效果（Line Effect）

**使用场景**：Q 技能未闭合状态

**实现方式**：
```gdscript
SkillEffectManager.create_line_effect({
    "start": Vector2,           # 起点
    "end": Vector2,             # 终点
    "width": float,             # 线条宽度
    "damage": int,              # 伤害值
    "damage_interval": float,   # 伤害间隔
    "duration": float,          # 持续时间
    "color": Color,             # 颜色
    "pull_to_line": bool,       # 是否吸附到线段
    "pull_force": float,        # 吸附力度
    "pull_interval": float      # 物理更新频率
})
```

**核心组件**：
- Area2D + RectangleShape2D（碰撞检测）
- Line2D（视觉效果）
- Timer（伤害 tick）
- Timer（物理 tick，可选）

### 4.2 区域效果（Area Effect）

**使用场景**：Q 技能闭合状态、E 技能范围效果

**实现方式**：
```gdscript
SkillEffectManager.create_area_effect({
    "polygon": PackedVector2Array,  # 多边形顶点
    "damage": int,                  # 伤害值
    "damage_interval": float,       # 伤害间隔
    "duration": float,              # 持续时间
    "color": Color,                 # 颜色
    "pull_to_center": bool,         # 是否吸附到中心
    "pull_force": float,            # 吸附力度
    "pull_interval": float,         # 物理更新频率
    "z_index": int,                 # 渲染层级
    "fade_in_duration": float,      # 淡入时间
    "fade_out_duration": float      # 淡出时间
})
```

**核心组件**：
- Area2D + CollisionPolygon2D（碰撞检测）
- Polygon2D（视觉效果）
- Timer（伤害 tick）
- Timer（物理 tick，可选）


### 4.3 墙体效果（Wall Effect）

**使用场景**：冰墙、电网等物理障碍

**实现方式**：
```gdscript
SkillEffectManager.create_wall_effect({
    "start": Vector2,               # 起点
    "end": Vector2,                 # 终点
    "width": float,                 # 墙体宽度
    "duration": float,              # 持续时间
    "block_enemies": bool,          # 是否阻挡敌人
    "block_bullets": bool,          # 是否阻挡子弹
    "contact_damage": int,          # 接触伤害（可选）
    "contact_interval": float,      # 伤害间隔（可选）
    "color": Color                  # 颜色
})
```

**核心组件**：
- StaticBody2D（物理碰撞）
- CollisionShape2D（碰撞形状）
- Line2D 或 Polygon2D（视觉效果）
- Area2D + Timer（接触伤害，可选）

### 4.4 Debuff 区域（Debuff Zone）

**使用场景**：减速、中毒、伤害放大等负面效果

**实现方式**：
```gdscript
SkillEffectManager.create_debuff_zone({
    "start": Vector2,               # 起点（线条）
    "end": Vector2,                 # 终点（线条）
    "polygon": PackedVector2Array,  # 多边形（区域）
    "width": float,                 # 宽度（线条）
    "duration": float,              # 持续时间
    "debuff_type": String,          # Debuff 类型
    "debuff_value": float,          # Debuff 数值
    "debuff_duration": float,       # Debuff 持续时间
    "tick_interval": float,         # 检测间隔
    "damage": int,                  # 伤害（可选）
    "damage_interval": float,       # 伤害间隔（可选）
    "color": Color                  # 颜色
})
```

**Debuff 类型**：
- `"slow"`：减速（debuff_value = 减速比例）
- `"freeze"`：冰冻/眩晕（debuff_value = 0.0）
- `"poison"`：中毒（debuff_value = 每秒伤害）
- `"damage_amp"`：伤害放大（debuff_value = 放大比例）


### 4.5 Buff 区域（Buff Zone）

**使用场景**：移速加成、护盾等正面效果

**实现方式**：
```gdscript
SkillEffectManager.create_buff_zone({
    "start": Vector2,               # 起点（线条）
    "end": Vector2,                 # 终点（线条）
    "polygon": PackedVector2Array,  # 多边形（区域）
    "width": float,                 # 宽度（线条）
    "duration": float,              # 持续时间
    "buff_type": String,            # Buff 类型
    "buff_value": float,            # Buff 数值
    "tick_interval": float,         # 检测间隔
    "color": Color                  # 颜色
})
```

**Buff 类型**：
- `"speed_boost"`：移速加成（buff_value = 加成比例）
- `"shield"`：护盾（buff_value = 护盾值）
- `"heal"`：治疗（buff_value = 每秒治疗量）

## 五、重构建议

### 5.1 提取公共效果类

建议创建以下效果基类：

#### `EffectBase`（效果基类）
```gdscript
class_name EffectBase
extends Node2D

var duration: float
var elapsed_time: float = 0.0
var is_active: bool = true

func _ready() -> void:
    pass

func _process(delta: float) -> void:
    if not is_active:
        return
    elapsed_time += delta
    if elapsed_time >= duration:
        _on_expired()

func _on_expired() -> void:
    queue_free()
```

#### `DamageEffect`（伤害效果）
```gdscript
class_name DamageEffect
extends EffectBase

var damage: int
var damage_interval: float
var damage_timer: Timer

func setup(params: Dictionary) -> void:
```

#### `PhysicsEffect`（物理效果）
```gdscript
class_name PhysicsEffect
extends EffectBase

var pull_force: float
var pull_to_center: bool
var pull_to_line: bool
var line_start: Vector2
var line_end: Vector2
var physics_timer: Timer

func setup(params: Dictionary) -> void:
    pull_force = params.get("pull_force", 0.0)
    pull_to_center = params.get("pull_to_center", false)
    pull_to_line = params.get("pull_to_line", false)
    line_start = params.get("start", Vector2.ZERO)
    line_end = params.get("end", Vector2.ZERO)
    
    physics_timer = Timer.new()
    physics_timer.wait_time = params.get("pull_interval", 0.05)
    physics_timer.autostart = true
    add_child(physics_timer)
    physics_timer.timeout.connect(_on_physics_tick)

func _on_physics_tick() -> void:
    # 应用物理效果
    if pull_to_center:
        _pull_to_center()
    elif pull_to_line:
        _pull_to_line()

func _pull_to_center() -> void:
    var center = global_position
    for enemy in _get_enemies_in_range():
        var dir = (center - enemy.global_position).normalized()
        enemy.global_position += dir * pull_force * physics_timer.wait_time

func _pull_to_line() -> void:
    for enemy in _get_enemies_in_range():
        var closest = Geometry2D.get_closest_point_to_segment(
            enemy.global_position, line_start, line_end
        )
        var dir = (closest - enemy.global_position).normalized()
        enemy.global_position += dir * pull_force * physics_timer.wait_time
```

#### `DebuffEffect`（Debuff 效果）
```gdscript
class_name DebuffEffect
extends EffectBase

var debuff_type: String
var debuff_value: float
var debuff_duration: float
var tick_interval: float
var tick_timer: Timer

func setup(params: Dictionary) -> void:
    debuff_type = params.get("debuff_type", "")
    debuff_value = params.get("debuff_value", 0.0)

    tick_timer.wait_time = tick_interval
    tick_timer.autostart = true
    add_child(tick_timer)
    tick_timer.timeout.connect(_on_tick)

func _on_tick() -> void:
    for enemy in _get_enemies_in_range():
        _apply_debuff(enemy)

func _apply_debuff(enemy: Node2D) -> void:
    if not enemy.has_method("apply_status"):
        return
    
    match debuff_type:
        "slow":
            enemy.apply_status("slow", debuff_duration, debuff_value)
        "freeze":
            enemy.apply_status("freeze", debuff_duration, 0.0)
        "poison":
            enemy.apply_status("poison", debuff_duration, debuff_value)
        "damage_amp":
            enemy.apply_status("damage_amp", debuff_duration, debuff_value)
```

### 5.4 效果池管理

为了优化性能，建议实现效果对象池：

```gdscript
class_name EffectPool

static var pools: Dictionary = {}

static func get_effect(effect_type: String) -> EffectBase:
    if not pools.has(effect_type):
        pools[effect_type] = []
    
    var pool = pools[effect_type]
    
    # 从池中获取
    for effect in pool:
        if not effect.is_active:
            effect.is_active = true
            return effect
    
    # 池中没有，创建新的
    var new_effect = _create_effect(effect_type)
    pool.append(new_effect)
    return new_effect

static func return_effect(effect: EffectBase) -> void:
    effect.is_active = false
    effect.visible = false
    effect.global_position = Vector2.ZERO

static func _create_effect(effect_type: String) -> EffectBase:
    match effect_type:
        "line_damage":
            return LineDamageEffect.new()
        "area_damage":
            return AreaDamageEffect.new()
        "wall":
            return WallEffect.new()
        "debuff_zone":
            return DebuffZoneEffect.new()
        _:
            return EffectBase.new()
```

## 九、F 技能系统架构详解

### 9.1 大招系统设计理念

F 键大招是所有角色的通用功能，采用"基础效果 + 角色特色"的设计模式：

#### 基础效果（所有角色共享）
- **武器爆炸效果**：激活期间，所有武器的攻击都会产生AOE爆炸伤害
- **视觉变身**：角色放大1.2倍，颜色变化
- **临时羁绊标签**：获得额外的羁绊标签（如 martial, destruction, alchemist）
- **能量消耗**：需要40%以上能量才能激活
- **持续时间**：默认10秒

#### 角色特色效果（9个特殊角色）
- **屠夫**：吸血提升+30%
- **烈焰者**：Q技能无冷却
- **商人**：击杀额外掉落金币，每2秒自动生成金币
- **炼金**：周围敌人持续受到伤害和石化减速
- **吸尘器**：持续将周围敌人拉向自身
- **处刑者**：处决阈值提升至50%，每秒自动处决低血量敌人
- **赌徒**：所有攻击必定暴击且攻击力翻倍
- **猎人**：持续标记范围内所有敌人增加受到的伤害
- **其他23个角色**：仅使用基础爆炸效果

### 9.2 大招实现架构

#### 基类：`SkillUltimate`（skill_ultimate_base.gd）

**核心功能**：
```gdscript
# 配置数据
var ult_id: String = ""
var ult_name: String = "Ultimate"
var duration: float = 10.0
var energy_cost: float = 40.0
var bonus_bond_tag: String = ""
var visual_color: Color = Color.WHITE
var scale_multiplier: float = 1.2

# 爆炸效果参数（所有角色共享）
var explosion_radius: float = 250.0        # 爆炸半径
var explosion_damage_scale: float = 1.0   # 爆炸伤害倍率

# 运行时状态
var is_active: bool = false
var remaining_time: float = 0.0
var player_ref: Node = null
```

**核心方法**：
- `try_activate()` - 尝试激活大招（检查能量）
- `_activate()` - 内部激活逻辑
- `deactivate()` - 停用大招
- `_apply_explosion_to_weapons()` - 为所有武器添加爆炸效果
- `_remove_explosion_from_weapons()` - 移除所有武器的爆炸效果
- `_apply_visuals()` - 应用变身视觉效果
- `_restore_visuals()` - 恢复原始视觉效果

**子类钩子（可重写）**：
- `_on_ultimate_activated()` - 大招激活时调用
- `_on_ultimate_deactivated()` - 大招停用时调用
- `_on_ultimate_update(delta)` - 大招激活期间每帧调用

### 9.3 武器爆炸效果实现

#### 爆炸效果添加流程

1. **查找玩家武器**：
   - 方法1：通过 `player.current_weapons` 数组
   - 方法2：递归搜索所有 Weapon 类型的子节点

2. **保存原始属性**：
   ```gdscript
   original_weapon_stats[weapon] = {
       "explosion_radius": stats.explosion_radius,
       "explosion_damage_scale": stats.explosion_damage_scale
   }
   ```

3. **设置爆炸属性**：
   ```gdscript
   stats.explosion_radius = explosion_radius
   stats.explosion_damage_scale = explosion_damage_scale
   ```

4. **恢复原始属性**（大招结束时）：
   ```gdscript
   stats.explosion_radius = original["explosion_radius"]
   stats.explosion_damage_scale = original["explosion_damage_scale"]
   ```

#### 爆炸效果参数说明

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| explosion_radius | float | 250.0 | 爆炸半径（像素），推荐范围：180-350 |
| explosion_damage_scale | float | 1.0 | 爆炸伤害倍率，推荐范围：0.8-1.5 |

**不同角色的爆炸参数**：
- **工兵**：半径350，倍率1.2（最大范围）
- **烈焰者**：半径300，倍率1.0（大范围）
- **吸尘器**：半径250，倍率1.0（标准）
- **赌徒**：半径250，倍率1.2（高伤害）
- **炼金**：半径200，倍率1.2（高伤害）
- **处刑者**：半径200，倍率1.5（最高伤害）
- **织网者**：半径180，倍率1.5（小范围高伤害）
- **御风者**：半径250，倍率0.8（大范围低伤害）

#### 示例4：处刑者大招（死刑宣告）

```gdscript

class_name SkillUltimateExecutioner

var execute_radius: float = 250.0
var execute_damage: int = 9999

func _on_ultimate_activated() -> void:
    # 标记玩家，提升处决阈值
    if player_ref:
        player_ref.set_meta("ult_execute_threshold", enhanced_threshold)

func _on_ultimate_deactivated() -> void:
    # 移除标记
    if player_ref and player_ref.has_meta("ult_execute_threshold"):
        player_ref.remove_meta("ult_execute_threshold")

func _on_ultimate_update(delta: float) -> void:
    # 每1秒扫描一次，处决低血量敌人
    if not has_meta("_exec_timer"):
        set_meta("_exec_timer", 0.0)
    var t = get_meta("_exec_timer") + delta
    if t >= 1.0:
        t -= 1.0
        var enemies = get_tree().get_nodes_in_group("enemies")
        for enemy in enemies:
            if not is_instance_valid(enemy):
                continue
            if player_ref.global_position.distance_to(enemy.global_position) > execute_radius:
                continue
            if enemy.has_node("HealthComponent"):
                var hc = enemy.get_node("HealthComponent")
                if hc.max_health > 0 and hc.current_health <= hc.max_health * enhanced_threshold:
                    hc.take_damage(execute_damage)
                    Global.spawn_floating_text(enemy.global_position, "EXECUTE!", Color(0.6, 0.1, 0.1))
    set_meta("_exec_timer", t)
```

### 9.7 大招重构建议

#### 当前问题
- 9个特殊大招脚本，代码重复度高
- 配置和代码分离，不易维护
- 缺乏统一的效果管理

#### 重构方案

**方案1：效果组件化**
```gdscript
# 创建可复用的大招效果组件
class_name UltimateEffect

# 吸血效果组件
class UltimateLifestealEffect extends UltimateEffect:
    var bonus: float = 30.0
    func activate(): UpgradeManager.add_attribute_bonus("lifesteal", bonus)
    func deactivate(): UpgradeManager.add_attribute_bonus("lifesteal", -bonus)

# 无冷却效果组件
class UltimateNoCooldownEffect extends UltimateEffect:
    var skill_key: String = "q"
    func activate(): _remove_skill_cooldown(skill_key)
    func deactivate(): _restore_skill_cooldown(skill_key)

# 金币生成效果组件
class UltimateGoldGeneratorEffect extends UltimateEffect:
    var interval: float = 2.0
    var amount: int = 5
    func update(delta): _generate_gold_periodically(delta)
```

**方案2：配置驱动**
```csv
# ult_effects.csv - 大招效果配置
ult_id,effect_type,param1,param2,param3
butcher_ult,lifesteal_bonus,30.0,,
pyro_ult,no_cooldown,q,,
merchant_ult,gold_generator,2.0,5,
merchant_ult,gold_on_kill,10,,
midas_ult,aura_damage,15.0,200.0,0.5
executioner_ult,execute_threshold,0.5,250.0,1.0
```

**方案3：统一效果管理器**
```gdscript
class_name UltimateEffectManager

static var effect_factories: Dictionary = {
    "lifesteal_bonus": UltimateLifestealEffect,
    "no_cooldown": UltimateNoCooldownEffect,
    "gold_generator": UltimateGoldGeneratorEffect,
    "aura_damage": UltimateAuraDamageEffect,
    "execute_threshold": UltimateExecuteEffect,
}

static func create_effects(ult_id: String) -> Array[UltimateEffect]:
    var effects: Array[UltimateEffect] = []
    var configs = _load_effect_configs(ult_id)
    for config in configs:
        var effect_type = config["effect_type"]
        if effect_factories.has(effect_type):
            var effect = effect_factories[effect_type].new()
            effect.setup(config)
            effects.append(effect)
    return effects
```
