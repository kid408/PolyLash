# 完整游戏流程 (Complete Game Flow)

## 流程概览

PolyLash 的完整游戏流程从角色选择开始，经过属性强化、武器选择、装备羁绊，最终进入战斗。本文档详细说明每个环节的机制和玩法。

```
主菜单 → 角色选择 → 属性强化 → 武器选择 → 装备羁绊 → 进入游戏 → 波次战斗 → 商店升级 → 结算
```

---

## 一、主菜单

### 1.1 主菜单界面

玩家启动游戏后进入主菜单，可以选择：

- **开始游戏**：进入角色选择界面
- **设置**：调整音量、画质等
- **退出游戏**：关闭游戏


### 2.2 角色信息

点击角色可查看详细信息：

- **基础属性**：生命、能量、速度、护甲
- **羁绊标签**：三源、职能、战术
- **技能描述**：Q技能、E技能
- **特点说明**：角色定位和玩法

### 2.3 羁绊预览

选择角色时，右侧实时显示羁绊激活情况：

- **未激活**：灰色显示，显示 `0/N`
- **已激活**：高亮显示，显示 `Lv.X`
- **可激活**：闪烁提示，显示 `N/N`

## 三、属性强化系统

### 3.1 强化界面

确认角色后，进入属性强化界面：

```
┌─────────────────────────────────────┐
│  金币: 1000                         │
│                                     │
│  [生命值]    100 → 110  [+10金币]  │
│  [攻击力]     10 → 11   [+10金币]  │
│  [移动速度]  300 → 310  [+10金币]  │
│  [能量恢复]  0.5 → 0.6  [+10金币]  │
│  [暴击率]     5% → 6%   [+10金币]  │
│                                     │
│  [重置属性] [确认强化]              │
└─────────────────────────────────────┘
```

### 3.2 强化规则

- **初始金币**：1000金币
- **强化成本**：每次强化消耗10金币（递增）
- **强化上限**：每个属性最多强化10次
- **重置功能**：可以重置所有强化，返还金币

### 3.3 推荐强化策略

#### 坦克角色（屠夫、冰河）
1. 优先强化生命值（+10次）
2. 其次强化护甲（+5次）
3. 最后强化能量恢复（+5次）

#### 输出角色（火焰、疾风）
1. 优先强化攻击力（+10次）
2. 其次强化暴击率（+5次）
3. 最后强化移动速度（+5次）

#### 辅助角色（军医、弹药）
1. 优先强化能量恢复（+10次）
2. 其次强化移动速度（+5次）
3. 最后强化生命值（+5次）

## 四、武器选择系统

### 4.1 武器商店

属性强化后，进入武器商店：

```

│                                     │
│  [刷新商店 -20金币]                 │
│  [跳过购买]                         │
└─────────────────────────────────────┘
```

### 4.2 武器类型

武器分为三大类：

#### 近战武器（Melee）
- **圆形挥砍**：范围攻击，适合清小怪
- **扇形挥砍**：前方扇形，适合定向输出
- **突刺**：直线攻击，高伤害单体

#### 远程武器（Ranged）
- **物理弹道**：手枪、霰弹枪、冲锋枪
- **魔法弹道**：火球、冰锥、闪电
- **光束武器**：激光、射线

#### 特殊武器
- **治疗法杖**：恢复生命
- **召唤图腾**：放置炮塔
- **陷阱地雷**：布置陷阱

### 4.3 武器属性

每把武器有以下属性：

- **基础伤害**：武器的基础攻击力
- **攻击速度**：每秒攻击次数
- **射程/范围**：攻击距离或范围
- **特殊效果**：穿透、溅射、减速等

### 4.4 武器选择策略

#### 根据角色选择

| 角色类型 | 推荐武器 | 理由 |
|---------|---------|------|
| 坦克角色 | 近战圆形挥砍 | 范围清怪，近战安全 |
| 输出角色 | 远程物理/魔法 | 远程输出，保持距离 |
| 辅助角色 | 治疗法杖/召唤 | 提供辅助，不需要高伤害 |

#### 根据羁绊选择

| 羁绊 | 推荐武器 | 理由 |
|------|---------|------|
| 爆破师 | AOE武器（霰弹枪、火球） | 触发闭合图形伤害加成 |
| 筑墙者 | 近战武器 | 配合线条控制敌人 |
| 几何学家 | 精准武器（手枪、激光） | 配合小图形暴击 |

### 5.2 装备类型

装备分为以下几类：

#### 遗物（Relic）
- **骨骼类**：骨十字、骨头、骨笼
- **书籍类**：死灵书、卷轴、羊皮纸
- **头骨类**：人类头骨、鸟头骨、鹿头骨
- **饰品类**：戒指、项链、手套

#### 装备效果

每件装备提供：
1. **羁绊标签**：通过 `bond_grant` 字段
2. **属性加成**：生命、攻击、速度等
3. **特殊效果**：暴击、穿透、吸血等

### 5.3 装备选择策略

#### 策略1：集中羁绊

选择相同羁绊标签的装备，快速激活高等级羁绊：

```
示例：魔导流
- 角色：火焰（魔导）
- 装备1：骨十字（魔导）
- 装备2：死灵书（魔导）
- 装备3：人类头骨（魔导）

结果：魔导 Lv.2 (4/3) ✓
效果：
- 魔法回复速度+30%
- 击杀敌人回复5点魔法
```

#### 策略2：多元羁绊

选择不同羁绊标签的装备，激活多个Lv.1羁绊：

```
示例：均衡流
- 角色：屠夫（重装|筑墙者|突击型）
- 装备1：骨十字（魔导）
- 装备2：游侠徽章（游侠）
- 装备3：炼金瓶（后勤）

结果：
- 重装 Lv.1 (2/2) ✓
- 魔导 Lv.1 (2/2) ✓
- 游侠 Lv.1 (2/2) ✓
- 后勤 Lv.1 (2/2) ✓
```

## 七、波次战斗

### 7.1 波次机制

游戏共有**10个波次**，每波次敌人数量和强度递增：

| 波次 | 敌人数量 | 敌人类型 | 特殊机制 |
|------|---------|---------|---------|
| 1-3 | 10-20 | 基础敌人 | 无 |
| 4-6 | 20-30 | 基础+精英 | 精英敌人出现 |
| 7-9 | 30-40 | 精英+BOSS | BOSS敌人出现 |
| 10 | 50+ | 全类型 | 最终BOSS |

### 7.2 敌人类型

#### 基础敌人
- **近战敌人**：追逐玩家，近战攻击
- **远程敌人**：保持距离，发射弹道
- **自爆敌人**：接近玩家后自爆

#### 精英敌人
- **冲锋敌人**：快速冲刺攻击
- **召唤敌人**：召唤小怪
- **治疗敌人**：为其他敌人治疗

#### BOSS敌人
- **巨型敌人**：高生命，高伤害
- **分裂敌人**：死亡后分裂为多个小怪
- **技能敌人**：拥有特殊技能

### 7.3 战斗策略

#### 策略1：控制流

使用Q技能画线控制敌人：

```
1. 按住Q键进入规划模式（子弹时间）
2. 按住鼠标左键画线
3. 画出闭合图形困住敌人
4. 松开Q键执行技能
5. 使用武器攻击被困敌人
```

**适合羁绊**：筑墙者、几何学家

#### 策略2：爆发流

使用闭合图形触发高伤害：

```
1. 按住Q键进入规划模式
2. 快速画出闭合图形
3. 触发闭合图形伤害加成
4. 连锁反应清屏
```

**适合羁绊**：爆破师、魔导

#### 策略3：机动流

利用高移动速度风筝敌人：

```
1. 保持移动，避免被包围
2. 使用E技能快速脱离
3. 画线时利用速度优势
4. 速度转化为攻击力
```

**适合羁绊**：游侠、突击型

## 八、羁绊效果实战示例

### 8.1 魔导羁绊实战

**场景**：第5波次，敌人数量30+

**羁绊配置**：
- 魔导 Lv.2（魔法回复速度+30%，击杀回复5点魔法）
- 爆破师 Lv.1（闭合图形伤害+20%）

**战斗流程**：

```
1. 初始能量：1000/1000
2. 按住Q键，画出大圈（消耗300能量）
3. 闭合图形触发，造成伤害：
   - 基础伤害：100
   - 爆破师加成：100 * 1.2 = 120
4. 击杀5个敌人，回复能量：5 * 5 = 25
5. 魔法自然回复：0.5 * 1.3 = 0.65/秒
6. 10秒后能量恢复：25 + 0.65 * 10 = 31.5
7. 继续画线...
```

**效果分析**：
- 高魔法回复保证持续画线
- 击杀回复能量，形成正循环
- 闭合图形伤害加成提升清怪效率

---

### 8.2 重装羁绊实战

**场景**：第7波次，BOSS敌人出现

**羁绊配置**：
- 重装 Lv.2（生命上限+25%，画闭合图形时霸体）
- 筑墙者 Lv.2（线条持续时间+3秒，线条反伤）

**战斗流程**：

```
1. 角色生命：150 * 1.25 = 187.5
2. 按住Q键，画出闭合图形
3. 画线过程中被BOSS攻击：
   - 霸体效果：不被打断
   - 继续画线
4. 闭合图形生成墙体：
   - 持续时间：5 + 3 = 8秒
   - 反伤效果：敌人接触墙体受到30%攻击力伤害
5. BOSS被墙体困住：
   - 每秒受到反伤：10 * 0.3 = 3
   - 8秒总伤害：3 * 8 = 24
6. 使用武器攻击BOSS...
```

**效果分析**：
- 高生命值提升生存能力
- 霸体效果保证画线不被打断
- 反伤墙体持续伤害BOSS

---

### 8.3 游侠羁绊实战

**场景**：第6波次，精英敌人出现

**羁绊配置**：
- 游侠 Lv.2（移动速度+15%，速度转伤害）
- 几何学家 Lv.2（闭合容错+15像素，小图形暴击）

**战斗流程**：

```
1. 基础移动速度：300
2. 游侠加成：300 * 1.15 = 345
3. 速度转伤害：(345 - 300) / 300 * 0.5 = 7.5%
4. 基础攻击力：10
5. 最终攻击力：10 * 1.075 = 10.75
6. 按住Q键，快速画小圈：
   - 闭合容错：60 + 15 = 75像素
   - 更容易触发闭合
7. 小图形暴击触发：
   - 图形面积：10000（小于15000）
   - 暴击伤害：10.75 * 2 = 21.5
8. 快速移动，画多个小圈...
```

**效果分析**：
- 高移动速度提升伤害
- 闭合容错提升，更容易触发
- 小图形暴击，快速清怪

### 9.2 商店选项

- **升级效果**：伤害+20%，攻击速度+10%

- **强化上限**：无限制

### 9.3 商店策略

#### 前期（波次1-3）
- 优先购买装备，激活羁绊
- 适当强化生命值，提升生存

## 十二、常见问题

### Q1：如何快速激活高等级羁绊？

**答**：
1. 选择3个相同标签的角色
2. 购买对应标签的装备
3. 优先激活三源羁绊（需求数量较少）

### Q2：武器和装备哪个更重要？

**答**：
- 前期：装备更重要（激活羁绊）
- 中期：平衡发展
- 后期：武器更重要（提升输出）

### Q3：如何应对BOSS敌人？

**答**：
1. 使用Q技能画闭合图形困住BOSS
2. 利用羁绊效果（反伤、暴击）
3. 保持移动，避免被攻击
4. 切换角色，利用不同技能

### Q4：金币不够怎么办？

**答**：
1. 击杀敌人获得金币
2. 装备后勤羁绊（金币轨迹）
3. 优先购买关键装备
4. 跳过不必要的强化

### Q5：如何提高生存能力？

**答**：
1. 强化生命值和护甲
2. 激活重装羁绊（生命上限+60%）
3. 使用E技能快速脱离
4. 画线创建墙体阻挡敌人
