# PolyLash 游戏系统大纲

## 文档索引

本文档集详细介绍了 PolyLash 游戏的所有核心系统和机制。每个系统都有独立的文档进行深入讲解。

---

## 核心系统列表

### 1. 配置管理系统 (ConfigManager)
**文档**: `01_配置管理系统.md`

负责从 CSV 文件加载和管理所有游戏配置数据，包括角色、敌人、武器、波次、道具等。

**核心功能**:
- CSV 配置文件统一加载
- 配置数据缓存和快速访问
- 支持多种配置格式（字典、数组、键值对）

---

### 2. 全局状态管理系统 (Global)
**文档**: `02_全局状态管理系统.md`

管理游戏的全局状态，包括角色选择、角色切换、局内数据等。

**核心功能**:
- 角色选择和队伍管理
- 角色切换系统（支持1-2-3键切换）
- 角色状态保存和恢复
- 局内经验值、击杀数、金币统计
- 切换冷却系统（P4-1羁绊）

---

### 3. 数据持久化系统 (DataManager)
**文档**: `03_数据持久化系统.md`

管理金币、属性升级等持久化数据的存储和读取。

**核心功能**:
- 金币管理（获取、消费、存储）
- 属性升级系统（等级、加成值）
- Roguelike 模式支持（可选重置）
- 局内会话存档（防崩溃恢复）
- 随机武器商店

---

### 4. 存档管理系统 (SaveManager)
**文档**: `04_存档管理系统.md`

管理游戏存档槽位、设置数据的序列化和反序列化。

**核心功能**:
- 3个存档槽位管理
- 存档数据验证和损坏检测
- 游戏设置管理（显示、音频、游戏玩法）
- 时间格式化工具

---

### 5. 羁绊系统 (BondManager)
**文档**: `05_羁绊系统.md`

游戏的核心数值系统，通过羁绊标签提供属性加成和特殊机制。

**核心功能**:
- 三源标签统计（角色、装备、徽章）
- 羁绊等级激活和效果应用
- 属性修改器（stat_mod）
- 特殊机制（mechanic）
- 临时标签管理
- 变身过载模式

---

### 6. 武器系统 (WeaponConfigLoader)
**文档**: `06_武器系统.md`

管理武器配置、等级缩放和武器数据生成。

**核心功能**:

- 等级倍率系统（减少配置维护）

- 武器信息查询

## 数据流向

### 1. 游戏启动流程
```
ConfigManager 加载所有 CSV 配置
    ↓
SaveManager 加载存档和设置
    ↓
DataManager 加载金币和升级数据
    ↓
主菜单显示
```

### 2. 角色选择流程
```
玩家选择角色 → Global.selected_player_ids
    ↓
玩家选择武器 → Global.selected_player_weapons
    ↓
初始化角色状态 → Global.player_states
    ↓
进入游戏场景
```

### 3. 羁绊计算流程
```
BondManager.recalculate_active_bonds()
    ↓
统计角色标签 → current_bond_counts
    ↓
统计装备标签 → EquipmentManager
    ↓
统计徽章标签 → EmblemManager
    ↓
激活羁绊 → active_bonds
    ↓
应用属性修改 → PlayerBase
```

### 4. 商店购买流程
```
ShopManager.generate_shop_items()
    ↓
玩家选择物品 → ShopManager.purchase_item()
    ↓
扣除金币 → DataManager.spend_gold()
    ↓
应用效果 → ModifierManager / EquipmentManager
    ↓
重新计算羁绊 → BondManager
```

## 关键概念

### 羁绊标签 (Bond Tag)
- 角色自带3个标签：origin_tag, mastery_tag, tactic_tag
- 装备可提供 bond_grant 标签
- 徽章提供全局羁绊标签
- 标签数量达到阈值激活羁绊等级

### 修改器 (Modifier)
- 基于标签的数值修改系统
- 支持固定值（flat_add）和百分比（percent_add）
- 子集匹配：技能标签包含道具标签即生效

### 武器等级系统
- 每个武器有基础值和等级倍率
- 等级1-4，每级属性递增
- 减少配置维护成本

### 局内数据 vs 持久化数据
- 局内数据：经验值、击杀数、徽章（每局重置）
- 持久化数据：金币、属性升级（跨局保留）
