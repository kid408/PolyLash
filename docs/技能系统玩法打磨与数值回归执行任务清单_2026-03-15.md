## 2. 本轮硬性约束

1. 没有人类实机记录，不允许把“主观手感验证”写成已完成。
2. CLI 自动验收只能证明“系统链路成立”，不能代替“玩法成立”。
3. 每个角色至少要落盘 1 份主观验收记录，才能进入“通过 / 需调优 / 需重做”判定。
4. 数值回归至少要覆盖 `baseline / fun / fun_tuned / hardcore` 四套主预设。
5. 录制 / 回放样本扩充要优先覆盖“高机动 / 改向 / 回收 / 装填 / 伴走”这几类最容易出手感偏差的角色。
6. 未完成项只允许写 `【未开始】` 或 `【进行中】`，不能把“待人工验证”伪装成通过。

## 3. 统一验收维度

每个角色主观验收统一按下面 7 项记录，评分建议使用 `1-5`：

1. `Q 开线成立度`
   - 非闭合 Q 是否单独能起手、保命、改路、留资产
2. `Q 闭合收口感`
   - 闭合是否把前铺垫转成新局面，而不是只做伤害放大
3. `E 二次操作清晰度`
   - E 是否明确改写了方向、位置、状态、收益、归属或时机
4. `F 10 秒忙碌感`
   - F 是否逼玩家追、捡、伴走、换位或连续兑现
5. `单人开局稳定性`
   - 没有理想队友时，角色是否也能靠自己活并建立节奏
6. `切人接力价值`
   - 角色是否给后续队友留下了可继承的资产、口子、压血线或装填窗口
7. `高光可达性`
   - 高风险高收益操作是否真实可打出，而不是只存在于文档描述

数值回归统一关注下面 6 项：

- `冷却 / 消耗`
- `覆盖率 / 命中率`
- `前摇 / 后摇 / 判定宽容度`
- `保底收益 / 上限收益`
- `单刷压力`
- `组队放大系数`
