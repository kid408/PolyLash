# 技能系统\n\n## 技能类型\n\n### 主动技能\n\n需要手动触发的技能。\n\n**特点**:\n- 需要按键触发\n- 有冷却时间\n- 消耗能量或资源\n- 有明显的效果\n\n**示例**:\n- 斩击 - 近距离斩击\n- 火球 - 投射火球\n- 冲刺 - 高速移动\n\n### 被动技能\n\n自动生效的技能。\n\n**特点**:\n- 无需触发\n- 持续生效\n- 提升属性\n- 无冷却时间\n\n**示例**:\n- 生命恢复 - 每秒恢复生命值\n- 伤害提升 - 增加基础伤害\n- 速度提升 - 增加移动速度\n\n### 增益技能\n\n提升玩家属性的技能。\n\n**特点**:\n- 提升基础属性\n- 增加伤害或防御\n- 改善移动或攻击\n- 持续生效\n\n**示例**:\n- 力量提升 - 增加伤害\n- 防御提升 - 增加防御\n- 速度提升 - 增加速度\n\n## 技能配置\n\n### player_skills.csv\n\n**列说明**:\n\n| 列名 | 类型 | 说明 |\n|------|------|------|\n| player_id | 字符串 | 玩家 ID |\n| skill_id | 字符串 | 技能唯一标识 |\n| skill_name | 字符串 | 技能名称 |\n| skill_type | 字符串 | 技能类型（主动/被动/增益） |\n| cooldown | 数字 | 冷却时间 |\n| energy_cost | 数字 | 能量消耗 |\n| damage_multiplier | 数字 | 伤害倍数 |\n| range | 数字 | 技能范围 |\n| duration | 数字 | 持续时间 |\n| description | 字符串 | 技能描述 |\n\n**示例**:\n```csv\nplayer_id,skill_id,skill_name,skill_type,cooldown,energy_cost,damage_multiplier,range,duration,description\nbutcher,slash,斩击,主动,0.5,0,1.2,100,0,近距离斩击\nbutcher,whirlwind,旋风斩,主动,2.0,30,1.8,150,0,旋转斩击\nbutcher,regeneration,生命恢复,被动,0,0,0,0,0,每秒恢复5生命值\n```\n\n## 技能升级\n\n### 升级系统\n\n**升级效果**:\n- 增加伤害\n- 减少冷却时间\n- 增加范围\n- 增加效果持续时间\n- 减少能量消耗\n\n### 升级配置\n\n**skill_params.csv**:\n```csv\nskill_id,level,damage_multiplier,cooldown,energy_cost,range,duration\nslash,1,1.2,0.5,0,100,0\nslash,2,1.4,0.4,0,120,0\nslash,3,1.6,0.3,0,140,0\nslash,4,1.8,0.2,0,160,0\n```\n\n## 技能机制\n\n### 冷却系统\n\n**冷却时间**:\n- 技能使用后进入冷却\n- 冷却期间无法使用\n- 冷却完成后可再次使用\n\n**冷却显示**:\n- UI 显示冷却进度\n- 冷却完成时提示\n\n### 能量系统\n\n**能量消耗**:\n- 使用技能消耗能量\n- 能量不足无法使用\n- 能量自动恢复\n\n**能量恢复**:\n- 每秒恢复固定能量\n- 击杀敌人恢复能量\n- 获得能量道具\n\n### 范围系统\n\n**技能范围**:\n- 近距离技能: 50-150 像素\n- 中距离技能: 150-300 像素\n- 远距离技能: 300-500 像素\n\n**范围效果**:\n- 单体技能: 只影响一个敌人\n- 范围技能: 影响范围内所有敌人\n- 直线技能: 影响直线上的敌人\n\n## 技能效果\n\n### 伤害效果\n\n**伤害类型**:\n- 物理伤害 - 基础伤害\n- 魔法伤害 - 魔法伤害\n- 真实伤害 - 无视防御\n\n**伤害计算**:\n```\n最终伤害 = 基础伤害 × 伤害倍数 × 暴击倍数\n```\n\n### 控制效果\n\n**控制类型**:\n- 眩晕 - 无法移动\n- 减速 - 移动速度降低\n- 冻结 - 完全冻结\n- 击退 - 被击飞\n\n### 增益效果\n\n**增益类型**:\n- 伤害提升 - 增加伤害\n- 防御提升 - 增加防御\n- 速度提升 - 增加速度\n- 生命恢复 - 恢复生命值\n\n### 负面效果\n\n**负面类型**:\n- 燃烧 - 持续伤害\n- 中毒 - 持续伤害\n- 流血 - 持续伤害\n- 虚弱 - 伤害降低\n\n## 技能脚本\n\n### 基础技能类\n\n```gdscript\nextends Node\nclass_name Skill\n\n@export var skill_id: String\n@export var skill_name: String\n@export var cooldown: float = 1.0\n@export var energy_cost: int = 0\n@export var damage_multiplier: float = 1.0\n\nvar is_on_cooldown: bool = false\nvar cooldown_timer: float = 0.0\n\nfunc _ready() -> void:\n    # 初始化技能\n    pass\n\nfunc _process(delta: float) -> void:\n    # 更新冷却\n    if is_on_cooldown:\n        cooldown_timer -= delta\n        if cooldown_timer <= 0:\n            is_on_cooldown = false\n\nfunc use_skill() -> void:\n    # 检查冷却\n    if is_on_cooldown:\n        return\n    \n    # 检查能量\n    if Global.player.energy < energy_cost:\n        return\n    \n    # 消耗能量\n    Global.player.energy -= energy_cost\n    \n    # 执行技能效果\n    _execute_skill()\n    \n    # 启动冷却\n    is_on_cooldown = true\n    cooldown_timer = cooldown\n\nfunc _execute_skill() -> void:\n    # 实现具体技能效果\n    pass\n```\n\n### 创建新技能\n\n**步骤**:\n1. 创建技能脚本\n2. 继承自 Skill 基类\n3. 实现 `_execute_skill()` 方法\n4. 在配置中添加技能\n5. 在玩家中绑定技能\n\n**示例**:\n```gdscript\nextends Skill\nclass_name SkillSlash\n\nfunc _execute_skill() -> void:\n    # 创建斩击效果\n    var slash_area = Area2D.new()\n    slash_area.global_position = Global.player.global_position\n    \n    # 检测敌人\n    var enemies = slash_area.get_overlapping_areas()\n    for enemy_area in enemies:\n        var enemy = enemy_area.get_parent()\n        if enemy is Enemy:\n            var damage = int(Global.player.stats.damage * damage_multiplier)\n            enemy.take_damage(damage)\n```\n\n## 技能平衡\n\n### 伤害平衡\n\n**伤害范围**:\n- 低伤害技能: 0.8-1.2 倍\n- 中伤害技能: 1.2-1.8 倍\n- 高伤害技能: 1.8-2.5 倍\n\n**冷却平衡**:\n- 快速技能: 0.3-0.8 秒\n- 中速技能: 0.8-1.5 秒\n- 慢速技能: 1.5-3.0 秒\n\n### 能量平衡\n\n**能量消耗**:\n- 低消耗: 0-10\n- 中消耗: 10-30\n- 高消耗: 30-50\n\n**能量恢复**:\n- 每秒恢复: 5-10\n- 击杀恢复: 10-20\n\n## 调试\n\n### 调试命令\n\n```gdscript\n# 使用技能\nplayer.use_skill(\"slash\")\n\n# 升级技能\nplayer.upgrade_skill(\"slash\", 1)\n\n# 获取技能信息\nvar skill_info = player.get_skill_info(\"slash\")\nprint(skill_info)\n\n# 重置技能冷却\nplayer.reset_skill_cooldown(\"slash\")\n```\n\n### 常见问题\n\n**Q: 技能伤害太低？**\nA: 增加 `damage_multiplier` 属性值。\n\n**Q: 技能冷却太长？**\nA: 减少 `cooldown` 属性值。\n\n**Q: 技能能量消耗太多？**\nA: 减少 `energy_cost` 属性值。\n\n**Q: 技能范围太小？**\nA: 增加 `range` 属性值。\n\n---\n\n**最后更新**: 2026年1月17日\n
