# 8 个样板角色技能改造稿 v1（2026-03-21）

## 1. 文档目的

本文档用于把项目当前最重要的 `8` 个样板角色，按照最新确认的 `skill` 标准重新拉开差异，并收成一版可继续细化的角色样板稿。

本文档只做角色技能设计改造，不展开：

- 具体数值
- HUD
- 充能系统
- 封包掉落
- 代码实现

本文档默认同时遵守以下两份标准：

- [SKILL.md](/D:/wanglei/PolyLash/.codex/skills/character-skill-design/SKILL.md)
- [技能系统行动经济与资源原型总纲_v1_2026-03-21.md](/D:/wanglei/PolyLash/docs/技能系统行动经济与资源原型总纲_v1_2026-03-21.md)

## 2. 本轮改造的总目标

这 `8` 个角色之所以先做，不是因为它们数值最重要，而是因为它们最容易决定项目整体的战术脸谱。

本轮改造要解决 4 组核心问题：

- `butcher / jailer / trapper` 都会碰“限制怪群”，必须强行拉开成 `拴住`、`走错`、`入袋`
- `weaver / lurewarden` 都会碰“改位和露背”，必须拉开成 `勒成一团`、`追错目标`
- `blacksmith / quartermaster` 都会碰“支援资产”，必须拉开成 `加工升拍`、`补给刷新`
- `medic` 必须从“被动奶妈”改成“能把安全面推成反打面的战斗医疗角色”

本轮统一要求如下：

- 每个角色都必须有唯一的 `Q 主循环`
- 每个角色都必须有唯一的 `Q 闭合兑现方式`
- 每个角色都必须有唯一的 `F 收账方式`
- 每个角色都必须能明确说出“我为后手角色留下什么价值”
- 每个角色都必须能通过系统自检，不越过 `Q/E/dash/F` 的公共边界

## 3. 样板角色清单

- `butcher / 屠夫`
- `jailer / 狱警`
- `blacksmith / 铁匠`
- `weaver / 织网者`
- `lurewarden / 诱猎师`
- `medic / 军医`
- `quartermaster / 军需官`
- `trapper / 伏猎者`

## 4. butcher / 屠夫

- 一句话角色幻想：`把怪拴去死的人`
- 玩法签名：`血锯锚点 + 活动半径收缩 + 处刑口`
- 资源原型：`高储能型`
- `E` 偏置：`否`
- 角色核心差异：屠夫不是单纯围怪，也不是让怪走错门，而是把怪拴在一个越来越小、越来越危险的活动半径里，最后挤进处刑口
- `Q 非闭合`：斜着甩出一条血锯线，线尾打下一枚血锚。被线吃到的怪不是只掉血，而是被迫沿线朝锚点拖行，越挣扎越被压回锚点半径内
- `Q 闭合`：锚点与已有锯线收成一个血锯囚场，囚场不做成均匀圆，而是只留一个明显的 `处刑口`，怪被持续往这个口挤
- `E 单按`：血钩保底，把最近贴脸怪勾开或勾回，解决贴脸和漏网
- `E 接 Q`：接开放线时，把一只精英或漏网怪补拖到最近锯线上；接闭合时，把快跑出处刑口的目标重新塞回去
- `F`：按下后，锚点附近的怪不是全散，而是在锚半径和处刑口边惊惧退缩。玩家的最优动作不是继续兜圈，而是立刻冲回锚区沿拖行终点和处刑口狠狠干
- 我为别人留下什么：`锚点区`、`处刑口`、`被拴小活动半径的怪群`、`被拖行压血的重点目标`
- 我最擅长接住什么：`持续灼烧区`、`大范围爆发区`、`处刑线`、`低血斩杀`
- `dash` 高操作点：斜穿锯线换到锚点另一侧，让被拖行的怪连续吃两次切面并把处刑口朝自己想要的方向翻出来
- 自然 `Combo`：`斜开过脸锯线 -> E 血钩把精英补进线 -> dash 换到锚点对侧 -> 闭合出处刑口 -> F 冲回屠场收口`
- 与近邻角色的核心差异：屠夫的关键词是 `拴住`，不是狱警的 `走错`，也不是伏猎者的 `入袋`

## 5. jailer / 狱警

- 一句话角色幻想：`让怪自己走错门的人`
- 玩法签名：`合法口 / 错路侧 / 死门走廊`
- 资源原型：`高储能型`
- `E` 偏置：`否`
- 角色核心差异：狱警不是把怪拽到一点，也不是埋伏夹口，而是把整个战场改写成“你越想追我，越会走错路”
- `Q 非闭合`：开放线落地后是一排有朝向的审判门。门的一侧是合法侧，玩家可以过；另一侧是错路侧，怪从这边撞门会被弹回去或被迫绕路
- `Q 闭合`：把多段审判门收成禁域走廊。走廊里同时存在 `赦免口` 和 `死门`，怪会在你故意留出的假活路和错误回弹之间反复犯错
- `E 单按`：锁门保底，先把最近一扇关键门段彻底封严
- `E 接 Q`：接开放线时，可以旋门或改门向，把一条刚才还好走的路现场改坏；接闭合时，可以点死门，让走廊里那一批怪更难逃
- `F`：按下后，怪群表现成“慌着找出口”，但一直被你骗进假口和死门里。玩家这时像审判者一样沿着走廊往前追击，而不是站远处看门自己弹
- 我为别人留下什么：`合法口`、`死门`、`错误路径`、`反复回弹的窄走廊`
- 我最擅长接住什么：`别人做出的窄口`、`压缩区`、`障碍边`、`需要路径规训的怪群`
- `dash` 高操作点：从合法口穿过去再回手锁门，把自己留在生侧、把怪彻底关在错路侧
- 自然 `Combo`：`开门线切正路 -> E 旋门改坏一侧通路 -> dash 穿合法口换侧 -> 闭合成死门走廊 -> F 进走廊清判`
- 与近邻角色的核心差异：狱警的关键词是 `走错`，不是屠夫的 `被拴`，也不是伏猎者的 `踩袋口`

## 6. blacksmith / 铁匠

- 一句话角色幻想：`把战场加工成工坊的人`
- 玩法签名：`热锻带 + 锻位 + 熔锻升拍`
- 资源原型：`标准型`
- `E` 偏置：`否`
- 角色核心差异：铁匠的价值不是补给，不是刷新，而是把已有资产加工得更狠、更热、更值钱
- `Q 非闭合`：画出一条热锻带，线上散布 `空锻位` 和 `热槽`。自己的火花、投射物、召唤、陷阱、炮台，甚至后手角色的资产，都可以在经过这条线时被加工升温
- `Q 闭合`：把热锻带收成熔锻环。环内所有可加工资产统一升一拍；即使场上暂时没别人资产，也要能把环内线段和锻位自己炼成临时工火，保证单人时不空
- `E 单按`：回火重击保底，砸开贴脸怪，同时把自己周围最近一个热槽点亮
- `E 接 Q`：接开放线时，把最近热槽指定给某个关键资产或某段热带；接闭合时，指定熔锻环里的核心节点先爆一拍
- `F`：按下后不是“铁匠伤害更高”，而是“工坊开始追着怪打”。热槽、锻位和过热节点会沿玩家回冲路径连续爆工火，把怪往外烫退却不让它们彻底散掉
- 我为别人留下什么：`已升温资产网络`、`热槽`、`可加工区域`、`升拍窗口`
- 我最擅长接住什么：`炮台`、`陷阱`、`召唤物`、`投射物`、`可叠加节点`
- `dash` 高操作点：穿过热锻带时在落点补出一枚临时回火点，给下一拍 `E` 或闭合升拍创造更值的钱点
- 自然 `Combo`：`先铺热锻带 -> E 把热量喂给关键锻位 -> 切资产或继续拖怪 -> F 冲回热区连爆 -> 闭合整环统一升拍`
- 与近邻角色的核心差异：铁匠的关键词是 `加工升拍`，不是军需官的 `补给刷新`

## 7. weaver / 织网者

- 一句话角色幻想：`把怪勒成一团的人`
- 玩法签名：`丝路切退路 + 回收拽团 + 网囊收紧`
- 资源原型：`标准型`
- `E` 偏置：`否`
- 角色核心差异：织网者不是做口袋，也不是让怪追错，而是把一群原本散开的怪横着勒成一团
- `Q 非闭合`：斜开一条丝路切断怪群退路，线尾优先挂墙角、窄口或障碍边。怪一旦擦到丝路，会被黏住退路并在延迟后被横向回收
- `Q 闭合`：把多段丝路收成一个网囊。圈内怪不是停在地上，而是会被持续往囊心勒，越想散开越被重新拽回
- `E 单按`：强收保底，把最近贴脸怪横着扯开，先救自己
- `E 接 Q`：接开放线时，沿最近丝线强行把高威胁目标拉进丝路中段；接闭合时，再勒紧囊口，把快逃出去的怪抽回网囊核心
- `F`：按下后，怪群最强的体感是“越想跑越被缠”。玩家不是站网外看，而是冲进自己做好的囊口里狠狠干那一团被勒紧的猎物
- 我为别人留下什么：`被拽成团的怪群`、`网囊`、`回收点`、`露背簇`
- 我最擅长接住什么：`别人先压低血的怪群`、`别人留下的减速区`、`障碍边的聚怪机会`
- `dash` 高操作点：穿囊口换边，引发丝束横向再拉一次，把本来要散开的怪重新勒回核心
- 自然 `Combo`：`丝路切退路 -> E 把精英强拽进线 -> dash 过囊口换边 -> 闭合做网囊 -> F 冲进囊里收人`
- 与近邻角色的核心差异：织网者的关键词是 `勒成一团`，不是伏猎者的 `收袋口`，也不是诱猎师的 `追错人`

## 8. lurewarden / 诱猎师

- 一句话角色幻想：`让怪追错东西的人`
- 玩法签名：`假路径 + 诱饵桩 + 错追露背`
- 资源原型：`标准型`
- `E` 偏置：`否`
- 角色核心差异：诱猎师的核心不是控住怪，而是改写怪的追击对象和朝向，让它们一直“追错”
- `Q 非闭合`：在地上画出一条假路径，线上布置诱饵桩和残影点。怪会明显朝错误目标和错误终点转过去，出现横转、慢半拍、露背
- `Q 闭合`：把假路径收成诱猎环。怪在环边会不断转头、换向、露背，看起来像一直在追错人
- `E 单按`：爆饵或换位保底，先把自己从危险位置摘出来
- `E 接 Q`：接开放线时，让最近一批怪再次改追击目标；接闭合时，指定诱猎环的一侧持续露背，方便玩家从那边切入
- `F`：按下后，玩家不是被动逃命，而是去猎杀一群被你骗得团团转的猎物。怪会横着转身、大片露背，却不会瞬间跑空
- 我为别人留下什么：`错朝向怪群`、`露背面`、`假路终点`、`诱饵桩周边的错误站位`
- 我最擅长接住什么：`别人压缩好的怪群`、`别人做出的窄口`、`需要集中露背的收割窗口`
- `dash` 高操作点：冲到诱饵对侧，让怪群为了追错目标再多转半圈，把整片露背面翻给自己或后手
- 自然 `Combo`：`开假路径 -> E 爆饵脱困或再误导一次 -> 站位开始错乱 -> F 反冲收背 -> 闭合成诱猎环继续逼出露背`
- 与近邻角色的核心差异：诱猎师的关键词是 `追错目标`，不是狱警的 `走错路`，也不是织网者的 `被拽成团`

## 9. medic / 军医

- 一句话角色幻想：`把安全面推成反打面的人`
- 玩法签名：`救治带 + 前插站 + 野战医院`
- 资源原型：`高回能型`
- `E` 偏置：`轻度允许，但不能越位`
- `E` 主优势类型：`E 冷却更短`
- 角色核心差异：军医不是软后勤，不是站后面奶，而是把“站在这里更安全”这件事变成主动进攻的资格
- `Q 非闭合`：铺出一条野战救治带，线上有救治站和安全点。玩家能直观看到“站在这里更稳、换血更赚、回撤更有路”
- `Q 闭合`：把救治站闭成野战医院。医院边缘会有急救脉冲、短净化窗和反压制面，让这块地方不只是能活，还能反打
- `E 单按`：急救保底，立刻抬一口血、给短护盾、解一次最关键的坏状态
- `E 接 Q`：接开放线时，把最近救治站前插，或者补一片短障把安全面推前；接闭合时，让医院超压，短时间内把医院边缘变成可赌命也可反打的高压区
- `F`：按下后，不是“奶量变高”，而是“战斗医疗冲锋”。医院边缘会连续打出急救电击和压制脉冲，怪在医院外缘退、顿、散半步，玩家因此敢顶着怪堆往里反打
- 我为别人留下什么：`医区`、`安全面`、`前插站点`、`适合换血的反打边`
- 我最擅长接住什么：`高风险近战角色`、`血量换资源的角色`、`需要据点作战的角色`
- `dash` 高操作点：冲过救治带时在落点吃一跳急救，让本来只够逃命的残血动作变成还能接着反手的抢命动作
- 自然 `Combo`：`铺救治带 -> E 急救或前插站 -> 把怪引到医区边缘 -> F 顶边反冲 -> 闭合成医院把这块地锁成据点`
- 与近邻角色的核心差异：军医的关键词是 `安全面` 与 `抢命反打`，不是圣卫那种硬墙推进，也不是军需官那种资源补给

## 10. quartermaster / 军需官

- 一句话角色幻想：`把后勤线推成进攻线的人`
- 玩法签名：`补给线 + 接管节点 + 军需回路`
- 资源原型：`标准型`
- `E` 偏置：`是`
- `E` 主优势类型：`E 命中后返还少量常规预算`
- 角色核心差异：军需官不是加工资产，而是让已有火力系统“不断有弹、不断有命令、不断有下一拍”
- `Q 非闭合`：画一条后勤补给线，线上布置补给箱、挂架和可接管节点。玩家本体、炮台、陷阱、召唤、投射，都可以沿这条线被补给、重装、缩短下一拍
- `Q 闭合`：把多个节点收成军需回路，让附近资产统一得到一次 `上膛 / 刷新 / 指令补发`
- `E 单按`：战术换弹保底，先把自己或最近资产立刻补满一轮，同时用压制火力拆贴脸
- `E 接 Q`：接开放线时，接管最近节点，让补给优先流向某一段线或某个关键资产；接闭合时，点一次全线刷新，让回路里所有资产统一上膛
- `F`：按下后，补给线会从后勤变成进攻路线。箱子、节点和挂架沿玩家回冲路线连续吐出装填、压制和短促火力，玩家因此越来越敢往怪堆深处追
- 我为别人留下什么：`补给线`、`已装填节点`、`军需回路`、`短时刷新窗口`
- 我最擅长接住什么：`任何需要下一拍的资产`、`炮台`、`陷阱`、`召唤物`、`高频技能角色`
- `dash` 高操作点：冲过补给节点时立刻点亮下一箱补给，把自己的回冲路线顺手改成一条可继续压前的火力线
- 自然 `Combo`：`铺补给线 -> E 接管关键节点 -> 关键资产先吃一轮 -> F 顺线前压追杀 -> 闭合成军需回路统一刷新`
- 与近邻角色的核心差异：军需官的关键词是 `补给刷新`，不是铁匠的 `加工升温`

## 11. trapper / 伏猎者

- 一句话角色幻想：`逼怪自己钻进猎袋的人`
- 玩法签名：`伏线 + 夹口 + 终猎袋`
- 资源原型：`标准型`
- `E` 偏置：`否`
- 角色核心差异：伏猎者不是把怪拽成团，也不是拴住一坨，而是提前把“从这个角度过去最亏”的袋口做出来，逼怪自己踩进去
- `Q 非闭合`：画出一排伏线和夹口。怪从错误角度穿过时，就像踩进一个还没完全收口的猎袋，会被咬住、改线、送去袋口
- `Q 闭合`：把多处夹口收成终猎袋。袋口不是平均收缩，而是会越来越紧，怪越想冲出来越容易撞回去
- `E 单按`：收线保底，先强触发最近夹口，拆掉贴脸压力
- `E 接 Q`：接开放线时，让还没咬上的伏线立刻咬住，或者直接改夹口朝向；接闭合时，把最近亮标目标强拉到袋口，变成最值钱的处刑点
- `F`：按下后，怪不是突然全散，而是意识到自己进袋了，开始朝袋口乱挤、回头、撞夹口。玩家此时像真正的猎人一样钻进自己收紧的猎袋里狠狠干
- 我为别人留下什么：`袋口`、`亮标目标`、`错误必经路`、`正在收紧的终猎袋`
- 我最擅长接住什么：`别人压缩过的怪群`、`窄口战场`、`点燃口袋边的持续区`
- `dash` 高操作点：从袋口穿过去，顺势把最近一只夹口在自己身后咬死，直接把退路切断
- 自然 `Combo`：`伏线改怪路 -> E 强触发最近夹口 -> dash 穿袋口反切退路 -> 闭合成终猎袋 -> F 钻袋追猎`
- 与近邻角色的核心差异：伏猎者的关键词是 `入袋`，不是织网者的 `勒团`，也不是屠夫的 `锚拴`

## 12. 第一轮系统自检结论

### 12.1 三组最关键的差异已经被拉开

- `butcher = 拴住`
- `jailer = 走错`
- `trapper = 入袋`

- `weaver = 勒成一团`
- `lurewarden = 追错目标`

- `blacksmith = 加工升拍`
- `quartermaster = 补给刷新`

- `medic = 安全面变反打面`

### 12.2 当前最稳的 4 个样板

这 4 个最适合先进入细化：

- `butcher`
- `jailer`
- `weaver`
- `lurewarden`

原因：

- 做局逻辑非常明确
- 和 `Q 主玩法` 的贴合度最高
- `F` 的“回场收账”也最容易成立

### 12.3 第二批需要仔细盯边界的 4 个样板

- `blacksmith`
- `medic`
- `quartermaster`
- `trapper`

需要重点盯住的问题：

- `blacksmith` 不能只剩“资产强化器”，必须保证单人时也有足够成立的自循环
- `medic` 不能退化回“只会奶”的软角色，必须一直保住反打资格
- `quartermaster` 很容易和 `blacksmith` 同构，必须始终把关键词锁在“补给刷新”
- `trapper` 很容易和 `weaver`、`butcher` 重叠，必须始终把关键词锁在“袋口”

## 13. 下一步建议

下一步最顺的顺序不是 8 个一起细抠，而是先按下面顺序逐个打磨：

1. `butcher`
2. `jailer`
3. `weaver`
4. `lurewarden`
5. `trapper`
6. `blacksmith`
7. `quartermaster`
8. `medic`

原因：

- 前 4 个最能先把 `Q 做局 -> E 改局 -> F 收账` 这条主结构打实
- `trapper` 需要建立在你已经接受 `butcher / jailer / weaver` 差异的基础上再收紧
- `blacksmith / quartermaster / medic` 更依赖你对支援、资产、据点这几个系统边界的容忍度

## 14. 本稿结论

如果按这版继续往下做，这 8 个样板角色已经具备作为“后续全角色扩写模板”的条件。

接下来每个角色真正要做的，不再是“再想一个更花的效果”，而是把下面 3 件事继续打实：

- 它的 `Q` 做局是不是一眼能认
- 它的 `F` 收账是不是逼玩家冲回自己做好的场里
- 它的价值交给下一个角色时，是不是依然看得见、接得住、值得接
