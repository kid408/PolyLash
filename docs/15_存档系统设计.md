## 概述

本游戏采用类似 Brotato 的存档机制，在关键节点自动保存进度，确保玩家可以随时退出并继续游戏。

## 设计理念

### 参考：Brotato 的存档机制
- **保存时机**：每次进入商店时自动保存
- **保存内容**：角色状态、物品、金币、波次进度
- **不保存内容**：战斗中的敌人（每波重新生成）

### 我们的实现
基于 Brotato 的设计，我们扩展了以下功能：
1. 支持多角色队伍系统
2. 支持羁绊系统的保存
3. 支持装备和仓库系统
4. 支持徽章和修改器系统

## 保存时机

### 1. 自动保存（Auto Save）
以下情况会自动触发保存：

#### 1.1 商店关闭时（主要保存点）
```gdscript
func _on_shop_next_wave_requested() -> void:
    _auto_save_progress("shop_closed")
    spawner.resume_spawning()
```
- **触发时机**：玩家点击"开始下一波"按钮
- **原因**：此时玩家已完成购买和升级，状态稳定
- **参考**：Brotato 也是在进入商店时保存

#### 1.2 角色切换时
```gdscript
func _on_player_switch_requested(player_id: String) -> void:
    _auto_save_progress("character_switch")
    # ... 切换角色逻辑
```
- **触发时机**：玩家按 Tab 或数字键切换角色
- **原因**：保存当前角色状态，防止数据丢失

#### 1.3 退出游戏时
```gdscript
func _on_exit_confirmed() -> void:
    _save_progress_before_exit()
    # ... 退出逻辑
```
- **触发时机**：玩家确认退出游戏
- **原因**：保存最终状态，确保进度不丢失

### 2. 手动保存（未实现）
未来可以添加手动保存功能，例如：
- 暂停菜单中的"保存游戏"按钮
- 快捷键保存（Ctrl+S）

## 不保存的内容

以下内容不会保存到存档中，每次加载时重新生成或计算：

### 1. 战斗中的敌人
- **原因**：每波敌人都是根据配置重新生成的
- **实现**：Spawner 根据波次配置生成敌人

### 2. 技能效果区域
- **原因**：技能效果有生命周期，会自动消失
- **实现**：重新进入游戏时，场景中没有残留的技能效果

### 3. 临时 Buff/Debuff
- **原因**：临时效果应该在战斗中消失
- **实现**：重新进入游戏时，所有临时效果清空

### 4. 相机状态
- **原因**：相机位置和缩放会自动重置
- **实现**：相机跟随当前角色

### 5. UI 状态
- **原因**：UI 状态（如打开的面板）不需要保存
- **实现**：重新进入游戏时，所有 UI 关闭

## 加载流程

### 1. 主菜单加载存档

```gdscript
# MainMenuRoot._on_menu_action("continue")
func _on_menu_action(action: String) -> void:
    match action:
        "continue":
            var slot_index = SaveManager.get_most_recent_slot()
            var data = SaveManager.load_game_save(slot_index)
            _restore_global_from_save(data)
            get_tree().change_scene_to_file("res://scenes/arena/arena.tscn")
```

### 2. 恢复数据到 Global

```gdscript
func _restore_global_from_save(data: Dictionary) -> void:
    # 恢复角色列表
    Global.selected_player_ids = [...]
    Global.selected_player_weapons = {...}
    
    # 恢复角色状态
    Global.player_states = data["player_states"]
    
    # 恢复金币和经验
    DataManager.save_data.total_gold = data["gold"]
    Global.session_xp = data["session_xp"]
    
    # 恢复徽章
    EmblemManager.deserialize(data["emblems"])
    
    # 恢复修改器
    ModifierManager.deserialize(data["modifiers"])
    
    # 恢复羁绊
    BondManager.restore_from_save(data["bond_counts"])
```

### 3. Arena 初始化

```gdscript
# Arena._ready()
func _ready() -> void:
    # 初始化玩家（从 Global 恢复状态）
    await _init_player_from_selection()
    
    # 恢复角色状态
    Global.restore_player_state(player)
    
    # 重新计算羁绊
    BondManager.recalculate_active_bonds(Global.selected_player_ids)
    
    # 应用羁绊属性
    player.apply_bond_stat_modifiers()
```

## 实现细节

### 1. 自动保存方法

```gdscript
func _auto_save_progress(trigger: String) -> void:
    """自动保存进度（在关键节点触发）"""
    var slot_index = Global.current_save_slot
    if slot_index < 0:
        return
    
    # 保存当前角色状态
    Global.save_current_player_state()
    
    # 构建完整的进度数据
    var progress = _build_save_data()
    
    # 添加触发信息
    progress["last_save_trigger"] = trigger
    progress["last_save_timestamp"] = int(Time.get_unix_time_from_system())
    
    # 保存到文件
    SaveManager.save_game_progress(slot_index, progress)
```

### 2. 构建存档数据

```gdscript
func _build_save_data() -> Dictionary:
    """构建完整的存档数据"""
    return {
        "current_wave": spawner.wave_index,
        "selected_players": _save_player_data(),
        "gold": DataManager.get_total_gold(),
        "bond_counts": BondManager.current_bond_counts.duplicate(true),
        "emblems": EmblemManager.serialize(),
        "modifiers": ModifierManager.serialize(),
        # ... 其他数据
    }
```

### 3. 保存角色数据

```gdscript
func _save_player_data() -> Array:
    """保存所有角色的数据"""
    var players_data = []
    
    for pid in Global.selected_player_ids:
        var state = Global.get_player_state(pid)
        players_data.append({
            "player_id": pid,
            "weapon_type": Global.selected_player_weapons.get(pid, ""),
            "health": state.get("health", 100),
            "max_health": state.get("max_health", 100),
            "is_dead": state.get("health", 100) <= 0,
        })
    
    return players_data
```

## 常见问题

### Q: 为什么不保存战斗中的敌人？
A: 参考 Brotato 的设计，每波敌人都是根据配置重新生成的。这样可以：
- 简化存档数据结构
- 避免保存大量敌人状态
- 确保每次加载时敌人行为一致

### Q: 如果在战斗中退出，会丢失进度吗？
A: 不会。退出时会保存当前波次和角色状态，下次加载时会从当前波次开始（重新生成敌人）。

### Q: 角色死亡后会保存吗？
A: 会。角色的死亡状态会保存到存档中，下次加载时该角色仍然是死亡状态。

### Q: 可以在战斗中保存吗？
A: 目前不支持。建议在商店中保存，或者退出游戏时自动保存。
