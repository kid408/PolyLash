# 32个样板角色技能设计与程序设计总稿 v2（2026-03-22）

## 1. 文档目的

本文档按最新 `character-skill-design` 与 `skill-program-design-standard` 规则，统一重做项目当前 `32` 个样板角色的技能设计与程序设计。

本稿遵守以下原则：

- 先完成角色设计，再完成程序设计
- 统一继承 `Q 非闭合 / Q 闭合 / E / dash / F` 技能框架
- 统一继承 `1 人开局 -> 局内扩编到 3 人 -> 1/2/3 切人` 的项目底盘
- 所有角色都必须保留单人存活底线
- 所有角色都必须优先服务多角色切换、留场接力、铺场扩利、窗口收口
- 所有角色都必须对标“旧屠夫节奏骨架”，而不是只做到字段完整
- 所有程序设计都只写行为目标、阶段、空间、规则、运行时对象、参数稿、验收，不把实现方式写死

## 2. 项目基础玩法设定

- 本项目是以 `Q 画线` 为主玩法本体的多角色小队动作游戏
- 玩家开局只选择 `1` 名角色进入战斗
- 玩家在局内逐步招募、替换到最多 `3` 人小队
- 玩家通过 `1 / 2 / 3` 键实时切换当前出战角色
- `Q 非闭合` 负责主循环、铺场、先手资产
- `Q 闭合` 负责高价值收口
- `E` 负责二次命令，不抢 `Q` 主位
- `dash` 负责低占用保命与兑现站位
- `F` 是高压高收益窗口，优先放大最近一次场面

## 3. 旧屠夫节奏标尺

以后所有角色都以旧屠夫的节奏骨架为标尺。对标的不是屠夫题材，而是下面这条爽链：

1. `Q非闭合` 先写下一条会改写战场秩序的结构
2. 这条结构被投出后立刻外化成真实战场对象
3. 敌人的位置、朝向、路径、危险面立刻发生变化
4. `Q闭合` 把开放结构收成单一高压结构，而不是普通圈技
5. `E` 对最近一次场面发出第二道命令
6. `dash` 把玩家送到最适合兑现的角度
7. `F` 唤醒最近一次场面并逼玩家回场收账

所有角色都必须回答：

- `Q非闭合` 是否真的在改写战场，而不是只在铺场
- `Q闭合` 是否收成单一高压结构，而不是普通伤害圈
- `E` 是否真的是第二道命令
- `dash` 是否主要服务兑现站位
- `F` 是否优先围绕最近一次场面收账
- 后手角色接到的是 `结构红利`，还是只有 `余伤/余波`

## 4. 统一时间、伤害、生存标准

### 4.1 时间层级

- `前台窗`：角色本人在场上直接做事、直接造成主效果的时间
- `残值窗`：主效果结束后，场上仍保留可读、可接、可转化状态的时间
- `后手兑现窗`：后一个角色进入后，仍能把前一个角色的残值转成自己收益的时间
- `三人协同寿命`：从第一个角色起手，到第三个角色完成主兑现，这条链可利用的总时间

### 4.2 默认时间标准

- `Q 非闭合`
  - 前台窗 `2.4s~3.2s`
  - 残值窗 `0.8s~1.5s`
  - 若承担起手资产，三人协同寿命必须能支撑 `4.5s+`
- `Q 闭合`
  - 前台窗 `2.0s~2.6s`
  - 残值窗 `0.6s~1.2s`
- `E`
  - 前台窗 `0.25s~0.45s`
  - 残值窗默认极弱或不保留
- `E->dash`
  - 联动窗 `0.3s~0.6s`
- `F`
  - 主窗口 `5.0s~6.5s`
  - 切人余波 `1.0s~1.5s`

### 4.3 伤害层级

- `起手控制型`：直接伤害低到中，空间与结构价值更高
- `持续压场型`：总伤害中到高，但重点是放大后手收益
- `收口斩杀型`：持续短，但兑现密度最高
- `F`：不是纯增伤，而是把前面铺好的价值一次性点活

### 4.4 单人存活底线

任何角色都至少保留一类自保手段：

- 近身脱离
- 短位移
- 短减伤
- 轻打断
- 临时护盾
- 低风险退场窗

## 5. 程序设计统一写法

每个角色程序段统一覆盖：

- `Q非闭合`
- `Q闭合`
- `E`
- `dash联动`
- `F`

每段至少写清：

- 时序
- 空间结构
- 敌人运动模型
- 首版持续时间
- 首版关键空间参数
- `context / asset`
- 验收重点

## 6. 32个角色总稿

## 6.1 butcher / 屠夫

### 角色设计

- `一句话角色幻想`：把敌人拴在错误活动半径里，再亲手拖去行刑
- `玩法签名`：`血索线 -> 肉钩回拖 -> 刑场口`
- `旧屠夫节奏对标结论`：`Q非闭合` 直接把战场写成血索拖行带；`Q闭合` 收成单一刑场口；`E` 把跑偏目标重新钉回结构；`dash` 服务回口与绕拖拽角；`F` 唤醒最近血索场并逼玩家回场收账
- `单角色爽点`：你能亲手把怪拽错、送错、压进错口
- `队伍配合爽点`：给火法、处刑人、破阵角色留下最清楚的收口点
- `最爽点`：`怪群被血索纠偏 -> 压进口区 -> 你补命令把要跑的重新拉回去`
- `最容易不爽的点`：线太粗、拖拽不明显、闭合像普通伤害圈
- `后手结构红利`：`位置红利`、`压缩红利`、`斩杀红利`
- `推荐连段链`：`屠夫 -> 焰术师 -> 处刑人`

### 程序设计

- `Q非闭合`：时序 `planning -> projected_launch 0.24s -> active 2.8s -> residual 1.2s`；空间为血索线、锚点、拖行带；普通怪沿线被持续纠偏并拖向锚点，精英减半，Boss 只吃锚点压力；首版参数 `线宽 64~72`、`锚点半径 96`、`有效长度 760`；`context / asset`：`q_open / butcher_line`；验收为“像一条会送人去错终点的线”
- `Q闭合`：时序 `closure_preview 0.18s -> compress 0.55s -> mouth_active 2.4s -> residual 1.0s`；空间为闭合区与单一刑场口；敌人先被压缩，再被持续送向口区；首版参数 `口宽 92`、`闭合半径 180~230`；`context / asset`：`q_closed / butcher_closure`；验收为“看起来是刑场口，不是红圈”
- `E`：时序 `hook_cast 0.12s -> reel 0.22s -> short_window 0.42s`；优先读取最近线心、锚点或口区，把高威胁目标钉回焦点；首版参数 `抓取半径 340`、`回拖位移 180`；`context / asset`：`butcher_hook / butcher_hook_window`；验收为“是第二道命令，不是补伤”
- `dash联动`：在 `0.45s` 联动窗内允许带目标短程移动并在结束时甩回锚点或口区；首版参数 `带人距离 140`、`甩回强度 中高`
- `F`：时序 `activate 0.16s -> field_awaken 5.8s -> residual 1.2s`；只强化最近一次血索线或刑场口，让压口、回拖、回场收益一起变强；`context / asset`：`f_activate / f_tick / f_deactivate`；验收为“玩家最优动作一定是回自己刑场里收账”

## 6.2 glacier / 冰河

### 角色设计

- `一句话角色幻想`：把战场切出裂口和冰壁，再把敌人震回断裂边界
- `玩法签名`：`霜线 -> 裂口 -> 返角碎裂`
- `旧屠夫节奏对标结论`：`Q非闭合` 把平面改成会滑移的寒线边界；`Q闭合` 收成单一裂口；`E` 命令最近裂口崩裂或封边；`dash` 负责切到返角；`F` 唤醒最近裂口，让玩家回边界收碎裂账
- `单角色爽点`：你能亲手把怪逼到一条危险边线上
- `队伍配合爽点`：给狱警、圣卫、处刑人留下高可读边口
- `最爽点`：`敌人被逼到裂口边 -> 你补震回 -> 一排碎裂`
- `最容易不爽的点`：只有减速，没有边界感
- `后手结构红利`：`位置红利`、`路径红利`、`斩杀红利`
- `推荐连段链`：`冰河 -> 圣卫 -> 处刑人`

### 程序设计

- `Q非闭合`：时序 `planning -> frost_throw 0.22s -> active 2.7s -> residual 1.1s`；空间为霜线与低摩擦边带；普通怪沿冰线滑偏，精英只吃角度修正，Boss 吃裂边减速；首版参数 `线宽 78`、`滑移偏角 18°~26°`；`context / asset`：`q_open / glacier_ridge`
- `Q闭合`：时序 `closure_lock 0.20s -> crack_open 0.48s -> fissure_active 2.3s -> residual 1.0s`；闭合后收成单一裂口，目标更易被弹回裂口边；首版参数 `裂口宽 110`、`返角碎裂半径 96`；`context / asset`：`q_closed / glacier_fissure`
- `E`：命令最近裂口瞬时封边或碎边，把准备越线的目标震回危险侧；首版参数 `封边 0.35s`、`震回距离 120`
- `dash联动`：`0.4s` 内 dash 穿裂口边缘可触发一次返角碎裂；首版参数 `返角扇区 70°`
- `F`：唤醒最近霜线或裂口，使边界更硬、返角更疼、后手更容易沿裂口收割；验收为“是回边界收碎裂，不是冰伤加强”

## 6.3 jailer / 狱警

### 角色设计

- `一句话角色幻想`：把路改错，把门改反，让敌人自己持续走进死门
- `玩法签名`：`改门向 -> 错路 -> 死门收押`
- `旧屠夫节奏对标结论`：`Q非闭合` 改写的是路径，不是伤害；`Q闭合` 收成单一死门；`E` 是改一次门向的命令；`dash` 负责站到判罚侧；`F` 唤醒最近错路结构并逼玩家回死门收押
- `单角色爽点`：你能让怪看起来像自己走错
- `队伍配合爽点`：和破阵、炮台、处刑、火区角色极强互补
- `最爽点`：`怪群转向错误门 -> 你补改门 -> 一批人自己进死门`
- `最容易不爽的点`：像空气墙、像抽象减速场
- `后手结构红利`：`路径红利`、`位置红利`
- `推荐连段链`：`狱警 -> 破阵督军 -> 处刑人`

### 程序设计

- `Q非闭合`：时序 `planning -> route_stamp 0.20s -> active 2.9s -> residual 1.4s`；空间为错路门片与导向走廊；普通怪目标点被重定向，精英只吃偏航，Boss 只吃门向惩罚；首版参数 `导向宽 120`、`错路距离 220`；`context / asset`：`q_open / jailer_route`
- `Q闭合`：时序 `closure_mark 0.18s -> deadgate_form 0.55s -> deadgate_active 2.2s -> residual 1.1s`；收成单一死门，进入门片的目标更难退回；首版参数 `门宽 96`、`门后缓冲深度 140`；`context / asset`：`q_closed / jailer_deadgate`
- `E`：命令最近门片翻向、锁向或短暂闭合，把即将逃出的敌人重新判进错误口；首版参数 `改门窗 0.38s`
- `dash联动`：穿门 dash 后在身后补一段短栅，使玩家能完成“先绕过去再关门”；首版参数 `补栅持续 0.55s`
- `F`：强化最近错路门组，让死门更稳定、退路更弱、后手更容易围绕门后口袋清算

## 6.4 blacksmith / 铁匠

### 角色设计

- `一句话角色幻想`：把战场和队友留下的资产一起敲进高工作态
- `玩法签名`：`工坊线 -> 炉口圈 -> 锻响兑现`
- `旧屠夫节奏对标结论`：`Q非闭合` 把地面写成加工轨；`Q闭合` 收成单一炉口；`E` 命令最近加工节点升温；`dash` 负责切到最佳锻击位；`F` 唤醒最近工坊场，让玩家回炉口收账
- `单角色爽点`：你不是单纯放地面伤害，而是在把战场锻成熟面
- `队伍配合爽点`：特别擅长接住任何控制、聚怪、导流类先手
- `最爽点`：`怪被压进工坊口 -> 你点火升温 -> 队友跟着在热面上收`
- `最容易不爽的点`：像普通火圈，缺少“加工态”
- `后手结构红利`：`持续伤害红利`、`位置红利`、`资源红利`
- `推荐连段链`：`控制角色 -> 铁匠 -> 破阵/炮台`

### 程序设计

- `Q非闭合`：时序 `planning -> forge_lane_drop 0.22s -> active 2.8s -> residual 1.3s`；空间为加工轨与锻击节点；轨上敌人会被缓慢推向工作热点；首版参数 `轨宽 88`、`热点间距 170`；`context / asset`：`q_open / smith_lane`
- `Q闭合`：时序 `closure_mark -> furnace_mouth 0.50s -> active 2.5s -> residual 1.0s`；收成单一炉口，进入者承受升温与受击放大；首版参数 `炉口宽 104`；`context / asset`：`q_closed / smith_furnace`
- `E`：命令最近节点升温、敲响或短促喷火，把加工态推入完成态；首版参数 `升温 1.0s`
- `dash联动`：锻击 dash 穿过热轨时在落点补一记冲锤，适合回到炉口正面；首版参数 `冲锤扇区 80°`
- `F`：唤醒最近工坊场，工作轨更热、炉口更值钱、队友资产也更容易进入高工作态

## 6.5 paladin / 圣卫

### 角色设计

- `一句话角色幻想`：把安全面推成反打面，让前线本身成为压迫线
- `玩法签名`：`圣线 -> 圣坛口 -> 反打前线`
- `旧屠夫节奏对标结论`：`Q非闭合` 改写的是前后安全关系；`Q闭合` 收成单一圣坛口；`E` 命令最近防线短时前顶；`dash` 负责切到盾前收线；`F` 唤醒最近前线结构并逼玩家在阵前收账
- `单角色爽点`：你能把“站住”直接变成“反推”
- `队伍配合爽点`：给破阵、军医、处刑、近战收割提供最稳定前台
- `最爽点`：`怪撞上圣线 -> 你顶线前推 -> 队友顺着正面集火`
- `最容易不爽的点`：只剩护盾数值，没有前线感
- `后手结构红利`：`位置红利`、`正面红利`
- `推荐连段链`：`冰河 -> 圣卫 -> 破阵督军`

### 程序设计

- `Q非闭合`：时序 `planning -> holy_front 0.18s -> active 3.0s -> residual 1.2s`；空间为圣线与正面缓冲区；普通怪撞线后被顶停，精英只吃推头，Boss 吃正面压制；首版参数 `前线长度 360`、`厚度 96`；`context / asset`：`q_open / paladin_front`
- `Q闭合`：收成单一圣坛口，口内是最安全也最适合反打的正面；首版参数 `坛口宽 116`、`口内减伤 0.8s`
- `E`：命令最近圣线短时前压，把进入线前的目标一起顶到正面惩戒区
- `dash联动`：圣冲 dash 可带着正面一起往前推进一段，强化“我冲过去，前线跟着走”
- `F`：唤醒最近防线，使圣线更硬、坛口更亮、反打收益更高；验收为“像推进阵面，不像单纯开无敌”

## 6.6 breachmarshal / 破阵督军

### 角色设计

- `一句话角色幻想`：顺着队友撕开的边和口，亲手把整段阵线撞开
- `玩法签名`：`裂阵线 -> 冲阵口 -> 贯穿收线`
- `旧屠夫节奏对标结论`：`Q非闭合` 把阵型写成可冲开的斜切线；`Q闭合` 收成单一冲阵口；`E` 命令最近破口再开一次；`dash` 就是冲口角度兑现；`F` 唤醒最近破口并逼玩家冲回去收线
- `单角色爽点`：你不是“有位移的战士”，而是“把口撞开的人”
- `队伍配合爽点`：最擅长接住狱警、冰河、圣卫、屠夫留下的收口点
- `最爽点`：`队友把怪导整齐 -> 你一冲把整条阵线掀开`
- `最容易不爽的点`：只像普通冲锋，没有开阵线体感
- `后手结构红利`：`位置红利`、`露背红利`
- `推荐连段链`：`狱警 -> 破阵督军 -> 处刑人`

### 程序设计

- `Q非闭合`：时序 `planning -> breach_lane 0.16s -> active 2.6s -> residual 0.9s`；空间为裂阵线与推进轴；敌人在轴上更容易被撞偏、露背、断阵；首版参数 `轴宽 84`、`推进长度 420`；`context / asset`：`q_open / breach_lane`
- `Q闭合`：收成单一冲阵口，口内目标承受更强的正面穿透与朝向错乱；首版参数 `口宽 108`
- `E`：命令最近破口再开一拍，把半乱不乱的阵线彻底掀散
- `dash联动`：在 `0.4s` 联动窗内 dash 穿口会触发一次贯穿波，把通道整成收割走廊
- `F`：强化最近裂阵结构，让冲口更稳、贯穿更长、回冲更值钱

## 6.7 hexwarden / 咒铠师

### 角色设计

## 7. 统一重点验收项

- 所有角色都必须先服务 `Q画线` 主循环，再把 `E / dash / F` 作为第二命令、换位联动和回场窗口
- 所有角色都必须留下可被后手角色接力的 `结构红利`，不能只留余伤
- 所有角色都必须通过“旧屠夫节奏标尺”审视
- 所有 `Q闭合` 都必须收成单一高压结构，不能退化成普通圈技
- 所有 `E` 都必须是对最近一次场面发出的第二道命令
- 所有 `dash` 都必须主要服务兑现站位
- 所有 `F` 都必须优先唤醒最近一次场面并逼玩家回场收账
- 所有角色都必须写清普通怪、精英、Boss 的运动模型差异
- 所有角色都必须写清单次释放最爽瞬间和最可能失真变平的风险点

## 8. 结论

这份重写版总稿不再沿用旧文档的拼接结构，而是统一成一份 `32` 角完整总稿。

重写后的核心变化是：

- 所有角色都从“字段完整”升级为“必须通过旧屠夫节奏标尺”
- 所有角色都显式对齐“先写结构 -> 投出结构 -> E 二次命令 -> dash 兑现站位 -> F 回场收账”的节奏链
- 所有程序设计都显式把 `普通怪 / 精英 / Boss` 的运动模型、持续时间、结构红利、回场验收写清
- 文档现在可以直接作为后续技能程序实施与表现打磨的统一上游依据
