# 暂停菜单与战斗状态保存系统

## 概述

实现了一个完整的暂停菜单系统，支持保存和恢复完整的战斗状态（包括玩家、敌人、物品等）。

## 功能特性

### 暂停菜单功能

1. **继续** - 恢复游戏
2. **重新开始** - 重新开始当前关卡
3. **结束本轮游戏** - 返回角色选择界面（清除战斗数据）
4. **图鉴** - 打开图鉴（待实现）
5. **设置** - 打开设置（待实现）
6. **返回主菜单** - 保存完整战斗状态，返回主菜单

### 战斗状态保存

系统会保存以下内容：

- **玩家状态**：位置、血量、能量、护甲、等级
- **敌人状态**：类型、位置、血量
- **物品状态**：场景中的所有物品
- **宝箱状态**：位置、是否已打开
- **波次状态**：当前波次、生成状态

### 保存机制

1. **返回主菜单**：保存完整战斗状态到 `battle_state` 字段，设置 `game_state = "in_battle"`
2. **结束本轮游戏**：清除 `battle_state` 字段，设置 `game_state = "character_selection"`
3. **继续游戏**：根据 `game_state` 决定跳转到哪个场景
   - `in_battle` + 有 `battle_state`：恢复战斗场景
   - `character_selection`：跳转到角色选择界面
   - 其他：默认进入战斗场景

## 配置步骤

### 1. 添加 BattleStateManager 到 Autoload

在项目设置中添加 autoload：

1. 打开 **项目 → 项目设置 → Autoload**
2. 添加新的 autoload：
   - **路径**：`res://autoloads/battle_state_manager.gd`
   - **节点名称**：`BattleStateManager`
   - **启用**：勾选

### 2. 在 Arena 场景中添加暂停菜单

暂停菜单会在 `arena.gd` 的 `_ready()` 函数中动态创建，无需手动添加到场景中。

### 3. 测试流程

#### 测试场景 1：返回主菜单并恢复

1. 开始新游戏，选择角色和武器
2. 进入战斗，击杀一些敌人
3. 按 ESC 打开暂停菜单
4. 点击"返回主菜单"
5. 在主菜单点击"继续游戏"
6. **预期结果**：回到战斗场景，玩家位置、血量、敌人位置都正确恢复

#### 测试场景 2：结束本轮游戏

1. 在战斗中按 ESC 打开暂停菜单
2. 点击"结束本轮游戏"
3. **预期结果**：返回角色选择界面
4. 在主菜单点击"继续游戏"
5. **预期结果**：跳转到角色选择界面（而不是战斗场景）

#### 测试场景 3：重新开始

1. 在战斗中按 ESC 打开暂停菜单
2. 点击"重新开始"
3. **预期结果**：重新加载当前场景，从第一波开始

## 实现细节

### BattleStateManager

负责保存和恢复战斗状态：

```gdscript
# 保存战斗状态
var state = BattleStateManager.save_battle_state()

# 恢复战斗状态
BattleStateManager.restore_battle_state(state)
```

### Arena 集成

在 `arena.gd` 中：

```gdscript
# 初始化时检查是否需要恢复战斗状态
if not Global.pending_battle_state.is_empty():
    await _restore_battle_state()
    Global.pending_battle_state = {}

# 返回主菜单时保存战斗状态
func _on_pause_return_to_menu() -> void:
    _save_full_battle_state()
    get_tree().change_scene_to_file("res://scenes/ui/main_menu/main_menu_root.tscn")
```

### MainMenuRoot 集成

在 `main_menu_root.gd` 中：

```gdscript
# 继续游戏时检查游戏状态
var game_state = data.get("game_state", "in_progress")
if game_state == "in_battle" and data.has("battle_state"):
    Global.pending_battle_state = data["battle_state"]
    get_tree().change_scene_to_file("res://scenes/arena/arena.tscn")
elif game_state == "character_selection":
    get_tree().change_scene_to_file("res://scenes/ui/selection_panel/selection_panel.tscn")
```

## 注意事项

### 1. 敌人场景路径

敌人必须有 `scene_file_path` 属性才能正确保存和恢复。确保敌人是从场景文件实例化的。

### 2. 投射物不保存

投射物通常不需要保存，因为它们会很快消失。如果需要保存，可以在 `BattleStateManager._save_projectiles_state()` 中实现。

### 3. 技能效果不保存

技能效果区域（如火焰、冰冻等）不会保存，重新进入游戏时会清空。

### 4. UI 状态不保存

UI 状态（如打开的面板）不会保存，重新进入游戏时所有 UI 关闭。

## 常见问题

### Q: 为什么敌人没有正确恢复？

A: 检查敌人的 `scene_file_path` 是否正确。敌人必须从场景文件实例化，而不是通过脚本创建。

### Q: 为什么玩家位置没有恢复？

A: 确保 `BattleStateManager._restore_player_state()` 在玩家初始化之后调用。

### Q: 如何清除战斗状态？

A: 调用 `Global.pending_battle_state = {}` 或在存档中删除 `battle_state` 字段。
