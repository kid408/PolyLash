## 方式1: 工具创建（推荐）

### 第一步：准备资源

在开始前，准备好：

1. **敌人图片** (PNG格式)
   - 放在 `assets/sprites/Enemies/` 文件夹
   - 建议大小: 64x64 到 128x128 像素
   - 透明背景

2. **敌人设计**
   - 名称（中文）
   - ID（英文，用下划线）
   - 基础属性数值

### 第二步：打开创建工具

```
1. 在Godot编辑器中
2. 打开文件: tools/create_enemy_tool.gd
3. 找到 create_enemy_interactive() 函数
```

### 第三步：填写配置

```gdscript
var config = {
    # === 基础信息 ===
    "enemy_id": "fire_demon",          # 英文ID（必填）
    "display_name": "火焰恶魔",         # 中文名称（必填）
    
    # === 基础属性 ===
    "health": 150,                     # 生命值
    "speed": 180,                      # 移动速度
    "damage": 18,                      # 攻击力
    "attack_range": 50,                # 攻击范围
    "attack_cooldown": 1.0,            # 攻击冷却（秒）
    
    # === 奖励 ===
    "xp_value": 15,                    # 经验值
    "gold_value": 8,                   # 金币
    "energy_drop": 2,                  # 能量掉落
    
    # === 视觉 ===
    "sprite_path": "res://assets/sprites/Enemies/FireDemon.png",
    "scale_x": 1.0,                    # X轴缩放
    "scale_y": 1.0,                    # Y轴缩放
    "color_r": 1.0,                    # 红色通道（0-1）
    "color_g": 0.5,                    # 绿色通道
    "color_b": 0.3,                    # 蓝色通道
    
    # === 特殊能力（可选）===
    "abilities": ["charge"]            # 能力列表
}
```

### 第四步：运行脚本

```
方法1: 菜单栏 -> File -> Run
方法2: 快捷键 Ctrl+Shift+X
方法3: 在脚本编辑器中点击运行按钮
```

### 第五步：查看结果

运行后，工具会自动：
1. ✅ 添加配置到 `enemy_config.csv`
2. ✅ 添加视觉配置到 `enemy_visual.csv`
3. ✅ 添加能力配置到 `enemy_abilities.csv`
4. ✅ 显示使用指南

### 第六步：测试敌人

```
1. 打开测试场景（或创建新场景）
2. 添加节点: scenes/unit/enemy/enemy_generic.tscn
3. 在Inspector中设置 Enemy Id 为 "fire_demon"
4. 按F5运行场景
5. 测试敌人行为
```

## 方式2: 手动配置

### 适用场景

- 需要批量修改敌人
- 需要精确控制每个参数
- 学习系统内部结构

### 配置文件详解

#### 文件1: enemy_config.csv

**位置**: `config/enemy/enemy_config.csv`

**作用**: 定义敌人的基础属性

**示例**:
```csv
enemy_id,display_name,health,speed,damage,attack_range,attack_cooldown,xp_value,gold_value,knockback_resistance,energy_drop,color_r,color_g,color_b,flock_push,stop_distance
fire_demon,火焰恶魔,150,180,18,50,1.0,15,8,0.5,2,1.0,0.5,0.3,20,60
```

**字段说明**:

| 字段 | 说明 | 默认值 | 示例 |
|-----|------|--------|------|
| enemy_id | 唯一标识符 | 无 | fire_demon |
| display_name | 显示名称 | 无 | 火焰恶魔 |
| health | 生命值 | 100 | 150 |
| speed | 移动速度 | 150 | 180 |
| damage | 攻击力 | 10 | 18 |
| attack_range | 攻击范围 | 50 | 50 |
| attack_cooldown | 攻击冷却 | 1.0 | 1.0 |
| xp_value | 经验值 | 10 | 15 |
| gold_value | 金币 | 5 | 8 |
| knockback_resistance | 击退抗性 | 0.5 | 0.5 |
| energy_drop | 能量掉落 | 2 | 2 |
| color_r/g/b | 颜色 | 1.0 | 1.0,0.5,0.3 |
| flock_push | 群聚推力 | 20 | 20 |
| stop_distance | 停止距离 | 60 | 60 |

#### 文件2: enemy_visual.csv

**位置**: `config/enemy/enemy_visual.csv`

**作用**: 定义敌人的视觉表现

**示例**:
```csv
enemy_id,sprite_path,scale_x,scale_y,color_r,color_g,color_b,color_a,z_index,offset_x,offset_y,collision_radius,hitbox_width,hitbox_height
fire_demon,res://assets/sprites/Enemies/FireDemon.png,1.0,1.0,1.0,0.5,0.3,1.0,0,0,0,20,40,40
```

**字段说明**:

| 字段 | 说明 | 默认值 |
|-----|------|--------|
| sprite_path | 精灵图片路径 | 必填 |
| scale_x/y | 缩放比例 | 1.0 |
| color_r/g/b/a | 颜色和透明度 | 1.0 |
| z_index | 渲染层级 | 0 |
| offset_x/y | 位置偏移 | 0 |
| collision_radius | 碰撞半径 | 20 |
| hitbox_width/height | 受击框大小 | 40 |

#### 文件3: enemy_abilities.csv

**位置**: `config/enemy/enemy_abilities.csv`

**作用**: 定义敌人的特殊能力

**示例**:
```csv
enemy_id,ability_id,cooldown,min_distance,max_distance,health_threshold,auto_activate,param1,param2,param3,param4
fire_demon,charge,3.0,100,300,0,1,0.8,0.6,3.5,30
```

**字段说明**:

| 字段 | 说明 | 默认值 |
|-----|------|--------|
| ability_id | 能力类型 | 必填 |
| cooldown | 冷却时间 | 3.0 |
| min_distance | 最小激活距离 | 0 |
| max_distance | 最大激活距离 | 999999 |
| health_threshold | 生命值阈值(0-1) | 0 |
| auto_activate | 自动激活(0/1) | 1 |
| param1-6 | 能力特定参数 | 见能力说明 |

### 手动配置步骤

1. **打开配置文件**
   ```
   用文本编辑器打开 config/enemy/ 下的CSV文件
   ```

2. **复制模板行**
   ```
   找一个相似的敌人，复制整行
   ```

3. **修改参数**
   ```
   修改 enemy_id 和其他需要的参数
   ```

4. **保存文件**
   ```
   确保使用 UTF-8 编码保存
   如果出现乱码，运行 config/convert_csv_utf8.bat
   ```

5. **重启游戏**
   ```
   重新加载配置
   ```

## 🎯 能力系统详解

### 可用能力

#### 1. poison_pool - 毒池

**效果**: 死亡时在地面留下持续伤害区域

**配置示例**:
```csv
enemy_id,ability_id,cooldown,min_distance,max_distance,health_threshold,auto_activate,pool_radius,pool_damage,pool_damage_interval,pool_lifetime
poison_spider,poison_pool,0,0,999999,0,1,60,5,0.5,8
```

**参数说明**:
- `pool_radius` (param1): 毒池半径，默认60
- `pool_damage` (param2): 每次伤害，默认5
- `pool_damage_interval` (param3): 伤害间隔（秒），默认0.5
- `pool_lifetime` (param4): 持续时间（秒），默认8

**适合的敌人类型**:
- 毒系怪物
- 地雷怪
- 爆炸型敌人

#### 2. shooting - 射击

**效果**: 向玩家发射投射物

**配置示例**:
```csv
enemy_id,ability_id,cooldown,min_distance,max_distance,health_threshold,auto_activate,projectile_count,arc_angle,projectile_speed,projectile_damage_mult
archer,shooting,3.0,0,300,0,1,3,45,1800,0.5
```

**参数说明**:
- `projectile_count` (param1): 投射物数量，默认3
- `arc_angle` (param2): 扇形角度（度），默认45
- `projectile_speed` (param3): 投射物速度，默认1800
- `projectile_damage_mult` (param4): 伤害倍率，默认0.5

**适合的敌人类型**:
- 弓箭手
- 法师
- 远程单位

#### 3. charge - 冲锋

**效果**: 向玩家冲刺攻击，有预警线

**配置示例**:
```csv
enemy_id,ability_id,cooldown,min_distance,max_distance,health_threshold,auto_activate,prep_time,charge_duration,speed_multiplier,warning_line_width
bull,charge,3.0,100,300,0,1,0.8,0.6,3.5,30
```

**参数说明**:
- `prep_time` (param1): 预警时间（秒），默认0.8
- `charge_duration` (param2): 冲锋持续时间（秒），默认0.6
- `speed_multiplier` (param3): 速度倍率，默认3.5
- `warning_line_width` (param4): 预警线宽度，默认30

**适合的敌人类型**:
- 公牛
- 野猪
- 冲锋型战士

### 能力组合示例

#### 组合1: 毒刺豪猪
```csv
# 既能冲锋，死后还留毒池
poison_hedgehog,charge,3.0,100,300,0,1,0.8,0.6,3.5,30
poison_hedgehog,poison_pool,0,0,999999,0,1,60,5,0.5,8
```

#### 组合2: 远程炮台
```csv

turret,shooting,2.0,0,400,0,1,5,90,2000,0.6
```

#### 组合3: 狂暴Boss
```csv
# 生命值低于50%时开始冲锋
boss,charge,5.0,100,400,0.5,1,1.0,0.8,4.0,40
```

```gdscript
# 紫色系（暗影）
color_r=0.8, color_g=0.3, color_b=1.0

# 橙色系（爆炸）
color_r=1.0, color_g=0.6, color_b=0.2
```

### 大小调整

```
小型敌人: scale = 0.7-0.9
标准敌人: scale = 1.0
大型敌人: scale = 1.2-1.5
Boss: scale = 1.5-2.5
```

### 碰撞体调整

```
碰撞半径 ≈ 精灵宽度 / 2 * scale
受击框 ≈ 精灵大小 * scale
```

## ❓ 常见问题解答

### Q1: 敌人创建后不显示？

**原因**:
- enemy_id 拼写错误
- 精灵路径不正确
- 配置文件未保存

**解决方案**:
```
1. 检查所有配置文件中的 enemy_id 是否一致
2. 确认精灵文件存在: assets/sprites/Enemies/xxx.png
3. 重启游戏重新加载配置
4. 查看控制台是否有错误信息
```

### Q2: 能力不生效？

**原因**:
- ability_id 拼写错误
- 激活条件不满足
- 配置参数错误

**解决方案**:
```
1. 检查 enemy_abilities.csv 中的配置
2. 确认 ability_id 正确: poison_pool, shooting, charge
3. 检查距离条件: min_distance, max_distance
4. 确认 auto_activate 设置为 1
```

### Q3: 配置修改后没有生效？

**原因**:
- 文件编码问题
- 缓存未清除
- 配置格式错误

**解决方案**:
```
1. 运行 config/convert_csv_utf8.bat 转换编码
2. 完全关闭并重启Godot
3. 检查CSV格式，确保没有多余的逗号或空格
4. 查看控制台错误信息
```

### Q4: 如何创建Boss？

**方法1: 简单Boss（推荐）**
```gdscript
{
    "enemy_id": "fire_boss",
    "display_name": "火焰领主",
    "health": 1500,
    "speed": 120,
    "damage": 50,
    "scale_x": 2.0,
    "scale_y": 2.0,
    "abilities": ["shooting", "charge"]
}
```

**方法2: 多阶段Boss（高级）**
```
参考 scenes/unit/enemy/elites/enemy_glutton.gd
需要编程知识
```

### Q5: 如何批量创建敌人？

**方法1: 使用工具**
```gdscript
var enemies = [
    {"enemy_id": "goblin", "display_name": "哥布林", ...},
    {"enemy_id": "orc", "display_name": "兽人", ...},
    {"enemy_id": "troll", "display_name": "巨魔", ...}
]

var tool = load("res://tools/create_enemy_tool.gd").new()
tool.create_enemy_batch(enemies)
```

**方法2: CSV复制**
```
1. 在CSV中复制一行
2. 修改 enemy_id 和其他参数
3. 粘贴多次
4. 保存文件
```
