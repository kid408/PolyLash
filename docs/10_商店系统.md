# 商店系统 (ShopManager)

## 系统概述

商店系统管理波次间商店的物品生成、购买和刷新逻辑，支持装备和徽章的混合生成。

**核心特点**:
- 装备 + 徽章混合生成
- 智能权重选择（优先未满级羁绊）
- 去重池机制（同局不重复）
- 商店刷新（Reroll）
- 唯一遗物检查

---

## 商店物品生成

### 生成规则
```gdscript
func generate_shop_items(count: int = 3) -> void
```

**生成流程**:
1. 清空当前商店物品
2. 对每个槽位：
   - 25% 概率生成徽章
   - 75% 概率生成装备
3. 使用去重池避免重复
4. 发出 `shop_items_generated` 信号

**示例**:
```gdscript
# 生成3个商店物品
ShopManager.generate_shop_items(3)

# 监听生成完成
ShopManager.shop_items_generated.connect(_on_shop_items_generated)

func _on_shop_items_generated(items: Array) -> void:
    print("商店物品: ", items.size())
    for item in items:
        print("  - ", item.get("item_name", ""), " (", item.get("price", 0), " 金币)")
```

## 徽章生成系统

### 智能权重选择
```gdscript
func _generate_emblem_item(used_ids: Array[String]) -> Dictionary
```

**权重规则**:
- 已拥有但未满级的羁绊: 3x 权重
- 未拥有的羁绊: 1x 权重
- 已满级的羁绊: 1x 权重

**排除规则**:
1. 去重池中的徽章
2. 已持有的唯一遗物
3. 万能鬼牌（仅从 Boss/隐藏房间获得）

**示例**:
```gdscript
# 当前羁绊状态:
# inkborn: 3/4 (Lv.2, 未满级) -> 3x 权重
# colossus: 0/2 (未拥有) -> 1x 权重
# nomad: 6/6 (Lv.3, 已满级) -> 1x 权重

# 生成徽章时，inkborn 相关徽章有更高概率出现
```

### 徽章配置
**来源**: `config/item/emblem_config.csv`

**字段**:
| 字段 | 说明 |
|------|------|
| emblem_id | 徽章ID（如 "emblem_inkborn"） |
| display_name | 显示名称 |
| artifact_type | 类型（emblem/relic） |
| bond_tag | 羁绊标签 |
| rarity | 稀有度（common/rare/epic） |
| shop_price | 商店价格 |
| is_unique | 是否唯一（1=是） |
| icon_path | 图标路径 |
| description | 描述 |

## 装备生成系统

### 权重随机
```gdscript
func _generate_equipment_item(used_ids: Array[String]) -> Dictionary
```

**生成流程**:
1. 构建权重池（排除去重池）
2. 根据 `shop_weight` 字段加权
3. 随机选择一个装备

**装备配置**:
**来源**: `config/item/shop_item_config.csv`

**字段**:
| 字段 | 说明 |
|------|------|
| item_id | 道具ID |
| item_name | 道具名称 |
| item_type | 道具类型（equipment/consumable） |
| item_tier | 道具等级（1-4） |
| effect_type | 效果类型 |
| effect_target | 效果目标（modifier/stat/bond） |
| target_tags | 目标标签（逗号分隔） |
| effect_value | 效果数值 |
| icon_path | 图标路径 |
| description | 描述 |
| price | 价格 |
| shop_weight | 商店权重（越高越容易出现） |
| is_trade_off | 是否有负面效果（1=是） |

## 购买系统

### 购买流程
```gdscript
func purchase_item(index: int) -> bool
```

**步骤**:
1. 验证索引有效性
2. 检查是否已购买
3. 检查金币是否足够
4. 扣除金币
5. 根据物品类型分支处理：
   - 徽章: 调用 `EmblemManager.add_emblem()`
   - 装备/消耗品: 应用物品效果
6. 标记为已购买
7. 发出 `item_purchased` 信号

**示例**:
```gdscript
# 购买第一个物品
if ShopManager.purchase_item(0):
    print("购买成功")
else:
    print("购买失败")

# 监听购买事件
ShopManager.item_purchased.connect(_on_item_purchased)

func _on_item_purchased(item_id: String, index: int) -> void:
    print("购买了: ", item_id)
```

### 购买失败原因
```gdscript
ShopManager.purchase_failed.connect(_on_purchase_failed)

func _on_purchase_failed(reason: String) -> void:
    match reason:
        "无效的物品索引":
            print("索引错误")
        "物品已购买":
            print("该物品已购买")
        "金币不足":
            print("金币不够")
        "无法添加该护符":
            print("唯一遗物已持有")
```

## 商店刷新

### 刷新机制
```gdscript
func reroll_shop() -> bool
```

**流程**:
1. 检查金币是否足够（默认50金币）
2. 扣除刷新费用
3. 重新生成商店物品
4. 发出 `shop_rerolled` 信号

**示例**:
```gdscript
# 刷新商店
if ShopManager.reroll_shop():
    print("商店已刷新")
else:
    print("金币不足，无法刷新")

# 监听刷新事件
ShopManager.shop_rerolled.connect(_on_shop_rerolled)

func _on_shop_rerolled() -> void:
    print("商店已刷新，请重新选择")
```

### 刷新费用
```gdscript
const REROLL_COST = 50  # 可在代码中修改

# 获取刷新费用
var cost = ShopManager.get_reroll_cost()
```

## 去重池机制

### 工作原理
1. 每次生成商店时创建空的去重池
2. 每生成一个物品，将其 ID 加入去重池
3. 后续生成时排除去重池中的物品

**示例**:
```gdscript
var used_ids: Array[String] = []

# 生成第一个物品
var item1 = _generate_equipment_item(used_ids)
used_ids.append(item1.get("item_id", ""))

# 生成第二个物品（不会重复第一个）
var item2 = _generate_equipment_item(used_ids)
used_ids.append(item2.get("item_id", ""))
```

**优点**:
- 避免同一商店出现重复物品
- 提高物品多样性
- 改善玩家体验

## 使用示例

### 完整的商店流程
```gdscript
# 1. 波次结束，打开商店
func open_shop() -> void:
    # 生成商店物品
    ShopManager.generate_shop_items(3)
    
    # 显示商店 UI
    shop_panel.show()

# 2. 玩家点击购买按钮
func _on_buy_button_pressed(index: int) -> void:
    if ShopManager.purchase_item(index):
        # 购买成功
        update_gold_display()
        update_item_button(index, true)
    else:
        # 购买失败（通过 purchase_failed 信号处理）
        pass

# 3. 玩家点击刷新按钮
func _on_reroll_button_pressed() -> void:
    if ShopManager.reroll_shop():
        # 刷新成功
        update_gold_display()
        regenerate_shop_ui()
    else:
        # 金币不足
        show_error_message("金币不足")

# 4. 玩家关闭商店
func close_shop() -> void:
    shop_panel.hide()
```

## 常见问题

### Q1: 为什么商店总是出现相同的物品？
**原因**: 权重设置不合理或物品池太小

**解决方案**:
1. 增加物品配置数量
2. 调整 `shop_weight` 字段
3. 检查去重池是否正常工作

### Q2: 徽章生成概率太低？
**原因**: `EMBLEM_SPAWN_CHANCE` 设置为 0.25（25%）

**解决方案**:
```gdscript
# 在 ShopManager 中修改
const EMBLEM_SPAWN_CHANCE: float = 0.40  # 改为 40%
```

### Q3: 唯一遗物重复出现？
**原因**: 唯一检查失效

**检查清单**:
1. 确认 `is_unique` 字段为 1
2. 检查 `EmblemManager.has_unique_relic()` 是否正常
3. 验证去重池是否包含该遗物

### Q4: 购买后效果没有生效？
**检查清单**:
1. 确认 `effect_target` 字段正确
2. 检查 `target_tags` 是否匹配
3. 验证 `ModifierManager` 或 `EquipmentManager` 是否正常工作
4. 检查是否触发了 `BondManager.stat_modifiers_changed` 信号

## 最佳实践

### 1. 物品设计原则
- 价格: 80-300 金币
- 权重: 5-20（常见物品10-15）
- 效果: 10-30% 加成

### 2. 徽章生成比例
- 25% 徽章 + 75% 装备（推荐）
- 可根据游戏进度调整

### 3. 刷新费用设计
- 初期: 50 金币
- 中期: 可考虑递增（如 50 -> 75 -> 100）

### 4. 去重池管理
- 每次生成商店时清空
- 跨波次不保留（允许重复）
