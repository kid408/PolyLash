## 一、 底层数据表解耦方案 (Data Decoupling)

为了彻底解决数值与多语言文本混杂的问题，请立即将现有的 `player_config.csv` 拆分为“纯数值表”与“本地化文本表”。

### 1. 数值核心表：`player_config.csv` (仅保留)
该表仅供游戏底层逻辑与战斗系统读取。
* **保留列**：`player_id`, `health`, `health_regen`, `skill_q_cost`, `skill_e_cost`, `energy_regen`, `max_energy`, `initial_energy`, `max_armor`, `base_speed`, `origin_tag`, `mastery_tag`, `tactic_tag` 等纯数据字段。
* **删除列**：`display_name`, `description` 以及其他所有长中文本。

### 2. UI 本地化文本表：`player_intro_cn.csv` (新建)
创建全新表结构，专供 UI 层面的多语言加载使用。表头结构如下：
* `player_id` (外键，与 config 表对应)
* `display_name` (展示名)
* `signature` (一句话签名)
* `experience_goal` (体验目标)
* `skill_unclosed` (右键未闭合描述)
* `skill_closed` (右键闭合描述)
* `skill_e` (E键技能描述)
* `skill_f` (F键终极技描述)

## 三、 UI 视觉红线规范 (UI Redline Spec)

禁用引擎默认的灰色风格，全面替换为“极简赛博/工业硬核”主题。

### 1. 全局色彩字典 (Color Palette)
| 颜色定义 | Hex 色值 | 适用场景 |
| :--- | :--- | :--- |
| **纯暗底色 (Bg_Base)** | `#0D1117` | 整个屏幕的最底层背景 |
| **模块底色 (Bg_Panel)** | `#161B22` | 左/中/右三个主要信息区块的底板，透明度 `90%` |
| **主高亮色 (Accent)** | `#00F0FF` | 选中的列表项、雷达图填充色、关键高亮字 |
| **副高亮色 (Warning)** | `#FF4655` | 致命代价、警告、技能消耗数值高亮 |
| **主文本 (Text_Primary)** | `#E6EDF3` | 角色名、技能标题、正文描述 |
| **副文本 (Text_Secondary)**| `#8B949E` | 未选中的列表项、属性标签 |
| **描边/分割线 (Border)** | `#30363D` | 区块细分割线 (宽度 `1px`) |

### 2. 字体排印规范 (Typography)
*使用无衬线硬朗字体 (如 Noto Sans / 思源黑体)。*
* **顶部大标题**: `36px`, Bold, 色值 `#E6EDF3`, 字间距 `+2px`
* **左栏 - 选中角色**: `24px`, Bold, 色值 `#00F0FF` (左侧配 `4px` 宽度的赛博青竖线指示器)
* **左栏 - 未选角色**: `20px`, Regular, 色值 `#8B949E`
* **中栏 - 一句话签名**: `18px`, Italic (斜体), 色值 `#E6EDF3` (附加 `70%` 透明度), 居中对齐
* **右栏 - 技能标题**: `22px`, Bold, 色值 `#E6EDF3` (底部带 `1px` `#30363D` 虚线)
* **右栏 - 正文内容**: `16px`, Regular, 色值 `#E6EDF3`, 行高倍率 `1.5`

### 3. 像素级模块化布局 (HBoxContainer)
屏幕横向划分为 3 个主区块，比例设定为 **25% (左) : 40% (中) : 35% (右)**。

* **【左侧：导航列表】**
  * Margin：左边界 `32px`，上边界 `32px`。
  * 列表项定高：`64px`。必须包含平滑的颜色过渡动画。
* **【中栏：视觉与属性核心 (核心防拥挤布局)】**
  * **错层悬浮设计**：不要将“立绘”和“属性雷达图”硬性上下切割。
  * **立绘区**：占据中栏上方，底部使用渐变透明遮罩 (Gradient Fade) 虚化融入深色背景。
  * **六边形雷达图区 (Radar Chart)**：绘制 `280x280px` 的六边形雷达图（六维：`生命`, `速度`, `能量上限`, `回蓝`, `爆发`, `控制`）。
  * **重叠布局 (Overlap)**：利用 Z-index 将雷达图置于最上层，并令其上方 **微微遮盖/重叠** 在立绘底部的透明虚化区域上（向上偏移约 `80px`）。此方案既大幅节省了垂直空间，又能营造出“全息数据面板投影在角色身前”的赛博科幻纵深感。
  * **图表样式**：雷达边框线色 `#30363D`，内填充色 `#00F0FF` 并附加 Alpha `40%` 和微弱 Glow 泛光。
* **【右侧：机制与阅读区】**
  * 根节点使用隐藏滚动条的 `ScrollContainer`。
  * **体验目标块**：背景色 `#0D1117`，边框 `1px` `#00F0FF`，左边框加粗至 `4px`，内边距 `16px`。
  * **技能列表**：间距 `24px`。图标固定 `48x48px` (圆角 `8px`，描边 `2px`)。右侧文本必须开启自动换行 (Auto Wrap)。
