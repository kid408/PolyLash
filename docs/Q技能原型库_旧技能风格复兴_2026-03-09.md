# QEF技能原型库（旧技能风格复兴，详细版，2026-03-09）

本文档用于头脑风暴和方案筛选，强调“可玩性、可配合、可切人连段”。

## 0. 文档目标与校验结论

你提出的要求是：
1. Q/E/F 数量一致，并扩展到 32 套。
2. Q 必须有非闭合和闭合两套逻辑。
3. E/F 必须能和 Q 配合或互补，不做孤立按钮。
4. 文档必须能看出具体玩法表现，不是只看名字。

当前版本采用“32 套技能卡”结构，每套都包含：
1. 玩法表现
2. Q 非闭合
3. Q 闭合
4. E 作用
5. F 作用
6. 优点
7. 缺点
8. 使用场景
9. 前置角色
10. 后置角色
11. 示例连招

---

## 1. 共通规则（所有Q都遵守）

1. 起点以鼠标为准，不以角色脚底为准。
2. 按住画线，松开结算。
3. 非闭合必须有效果，闭合是增强而不是唯一答案。
4. 非闭合偏“即时应对”，闭合偏“控场收割”。
5. E 负责补节奏和补短板，F 负责放大前面准备。

## 2. 32套技能卡（详细）

### 套件01 链束处刑（Q01+E13+F25）
玩法表现：把几何体甩出去，落点锁链圈禁敌人。
Q非闭合：飞轮沿轨迹前冲，路径切割并推挤怪群。
Q闭合：落点生成链束牢笼，敌人出圈会被拉回并流血。
E作用：链束加压，提升圈内减速与破甲强度。
F作用：破阵号令，锁定最大怪群集中处刑。
优点：控场稳定，适合打大群怪和精英波。
缺点：依赖站位，空放会亏节奏。
使用场景：中后期怪密集、精英混杂波次。
前置角色：`wind` 或 `herder` 先把怪推到同一方向。
后置角色：`pyro`、`executioner` 接爆发收尾。
示例连招：`wind` 拉扯 -> `butcher` Q闭合+E -> 切 `pyro` 火墙灼烧。

### 套件02 织网回收（Q02+E07+F02）
玩法表现：先铺网，窗口期再回收，二段决策感强。
Q非闭合：织网线切割并挂丝印，降低敌人移动。
Q闭合：二段收网把敌人拖回中心并触发爆发。
E作用：手动回收，提前引爆“收网时机”。
F作用：全域回收，让全场可回收体同时回卷。
优点：节奏可控，二段操作上限高。
缺点：需要玩家判断回收时机。
使用场景：追求“先控后爆”的小队配合。
前置角色：`wind` 先聚怪，或 `jailer` 先短控。
后置角色：`necro`、`plague` 补持续伤害。
示例连招：先画网挂印 -> 等怪进圈 -> E强制回收 -> F全域回卷。

### 套件03 围栏赶羊（Q03+E03+F14）
玩法表现：画线时角色冲刺，落地形成围栏。
Q非闭合：冲刺轨迹造成线伤，留下短时阻挡线。
Q闭合：围栏成圈，怪物被困并持续受击退。
E作用：快速封门，在缺口处补一道临时门。
F作用：猎场封锁，把战场切成安全区和猎杀区。
优点：地形控制强，防贴脸优秀。
缺点：对狭窄地图收益过高，空旷图弱一点。
使用场景：近战怪多、突进怪多的波次。
前置角色：`glacier` 先起墙缩路口。
后置角色：`ammo`、`turret_eng` 远程稳定输出。
示例连招：Q拉圈封路 -> E堵缺口 -> F猎场压制，远程安全点射。

### 套件04 火墙焚场（Q04+E15+F16）
玩法表现：线即火墙，闭合变火海。
Q非闭合：折线火墙持续灼烧，边缘伤害更高。
Q闭合：闭合后转火海，高频灼烧并触发爆燃。
E作用：热浪推进，把怪推回火线。
F作用：业火审判，把灼烧层统一转为爆发伤害。
优点：清怪快，视觉反馈强，爽点直接。
缺点：需要控制怪的移动，不然容易漏烧。
使用场景：小怪潮、召唤潮、中甲目标。
前置角色：`butcher`、`weaver` 先控住敌人。
后置角色：`executioner`、`hunter` 清残血。
示例连招：`butcher` 锁圈 -> `pyro` Q闭合 -> E热浪回推 -> F审判收场。

### 套件05 雷区爆破（Q05+E25+F22）
玩法表现：先埋雷，后连爆，典型延迟博弈。
Q非闭合：沿线埋雷，按时序逐颗爆炸。
Q闭合：形成雷核，触发雷网连锁爆。
E作用：定时引线，提前点燃关键目标。
F作用：工事狂欢，雷、塔、桩同时过载轰炸。
优点：爆发高，擅长打“怪潮转角”。
缺点：需要预判走位，操作前摇明显。
使用场景：大波次开始前 2~3 秒预铺场。
前置角色：`jailer`、`glacier` 先减速封路。
后置角色：`new_tempest`、`tesla` 做雷电补刀。
示例连招：提前布雷 -> 怪进场时E拉引线 -> F工事总爆，整屏清空。

### 套件06 冰墙封门（Q06+E14+F12）
玩法表现：真实冰墙改地形，闭合冻结圈。
Q非闭合：线段立墙，阻挡怪和部分投射物。
Q闭合：闭合圈周期冻结，破冰触发额外伤害。
E作用：冰封楔点控，沿冰墙快速扩散冻结。
F作用：冻结法典，让每次闭合附带冰爆。
优点：防线稳定，容错高。
缺点：输出不如纯爆发流，节奏偏慢热。
使用场景：高压生存波、弹幕密集波。
前置角色：`banner` 先开防御加成。
后置角色：`pyro`、`sapper` 在冻结期打满输出。
示例连招：Q拉墙堵门 -> E冰楔扩冻 -> F法典强化闭合冰爆。

### 套件07 替身牵制（Q07+E26+F17）
玩法表现：木桩替身拉仇恨，形成假目标战场。
Q非闭合：节点生成木桩，被打会反爆。
Q闭合：木桩间拉出幻链，穿链受罚。
E作用：影桩互换，和木桩瞬移换位。
F作用：影域替身军，复制替身形成短命军团。
优点：保命强，骗技能能力强。
缺点：对无仇恨AI目标收益一般。
使用场景：精英有高伤单点技能时。
前置角色：`illusionist` 先放干扰效果。
后置角色：`merchant`、`midas` 稳定经济滚雪球。
示例连招：Q放桩骗技能 -> E换位避伤 -> F召替身军反包围。

### 套件08 风轨回卷（Q08+E20+F11）
玩法表现：去程推怪、回程拉怪，双向拉扯。
Q非闭合：风轨去程把怪推离核心区。
Q闭合：回程改强拉，把怪拖回聚点。
E作用：轨道折返，让风轨再回卷一轮。
F作用：灾变折返，全图线段反向清扫。
优点：聚怪能力顶级，群战节奏流畅。
缺点：单体斩杀能力弱。
使用场景：配合AOE队友时收益极高。
前置角色：`herder` 先限定怪移动方向。
后置角色：`pyro`、`tesla` 做范围爆发。
示例连招：Q去程推散 -> 闭合回拉 -> E二次折返 -> 切火法爆发。

### 套件09 导轨弹幕（Q09+E27+F19）
玩法表现：改写弹道，让“弱子弹”变强覆盖。
Q非闭合：子弹穿线折射一次，扩大命中面积。
Q闭合：闭合后交叉点成为高伤节点。
E作用：弹幕校射，提升追踪和穿透。
F作用：共振坍缩，导轨末段集中挤压爆发。
优点：对高攻速/多弹道构筑增益巨大。
缺点：自身基础伤害依赖武器质量。
使用场景：远程主C队、弹幕流队伍。
前置角色：`ammo`、`hunter` 先铺弹幕。
后置角色：`new_tempest` 接雷电清场。
示例连招：Q铺导轨 -> E校射追踪 -> F坍缩收束，交叉点爆头。

### 套件10 尸印引爆（Q10+E04+F03）
玩法表现：先叠层再引爆，像引信玩法。
Q非闭合：线段命中挂尸印，层数可累加。
Q闭合：闭合结算尸印并向外扩散。
E作用：印记引爆，手动提早结算。
F作用：链式处决，对低血印记目标连斩。
优点：打群效率高，斩杀反馈强。
缺点：前摇期伤害偏低。
使用场景：怪物持续刷新的长波次。
前置角色：`swarm`、`train` 先制造低血群体。
后置角色：`executioner` 终结精英。
示例连招：Q先叠满尸印 -> E引爆压血线 -> F链斩一波带走。

### 套件11 封疗阵地（Q11+E22+F24）
玩法表现：同一条线敌方受压、友方受益。
Q非闭合：敌方穿线受伤，友方穿线回血回能。
Q闭合：生成战地圈，敌减疗、友抗控。
E作用：急救护幕，抬血线和解控。
F作用：逆转置换，把部分不利状态倒给敌人。
优点：打持久战很稳，容错高。
缺点：爆发不足，需要队友补伤害。
使用场景：Boss波和高压长战斗。
前置角色：`banner` 提前加防和减伤。
后置角色：`plague`、`necro` 慢慢磨血。
示例连招：Q铺封疗线 -> E护幕稳血 -> F逆转状态后反打。

### 套件12 延时回放（Q12+E12+F23）
玩法表现：先记录，再回放，打时间差。
Q非闭合：线段做标记并造成小伤。
Q闭合：延迟后完整回放路径重击。
E作用：临时共鸣，复制一段弱化回放。
F作用：时停剖面，停住敌人后统一结算。
优点：上限高，连招成就感强。
缺点：手残容易空技能。
使用场景：需要预判的精英波、Boss前摇期。
前置角色：`jailer`、`glacier` 先限制走位。
后置角色：`gambler`、`hunter` 趁停滞打爆发。
示例连招：Q画线埋“未来伤害” -> E补回放 -> F时停后一次炸满。

### 套件13 棱镜反制（Q13+E01+F05）
玩法表现：以防换攻，把敌方火力转成己方输出。
Q非闭合：棱镜线反弹一次投射和冲锋。
Q闭合：镜室内多次折返后爆发。
E作用：反冲脉冲，近身时瞬间自保并回推。
F作用：反制穹顶，形成全屏反弹窗口。
优点：针对弹幕/冲锋敌人很克制。
缺点：对慢速近战群收益中等。
使用场景：高投射敌人波次。
前置角色：`glacier` 先限制敌方角度。
后置角色：`tesla`、`ammo` 接远程收割。
示例连招：Q摆棱镜线 -> E防近身 -> F开穹顶把敌弹全部打回去。

### 套件14 磁轨换道（Q14+E24+F20）
玩法表现：改轨道、改路径、改站位。
Q非闭合：敌人触线被拖到指定轨道。
Q闭合：闭合区周期重排站位。
E作用：反向牵引，把敌人换层并过边界。
F作用：引力翻面，全图吸斥节奏切换。
优点：控场强，打乱敌群阵型。
缺点：需要玩家理解路径管理。
使用场景：多路线刷怪、围攻压力波。
前置角色：`herder` 先定向驱赶。
后置角色：`sapper` 在重排后引爆雷区。
示例连招：Q换道聚怪 -> E反拉穿边界 -> F吸斥循环压死怪群。

### 套件15 锚点突刺（Q15+E02+F18）
玩法表现：节点位移连刺，机动型输出。
Q非闭合：生成锚点，角色可短跃突刺。
Q闭合：闭合中心主锚，连续多段折返。
E作用：锚点跃迁，补位和追击。
F作用：锚点超载，连跳次数与落点爆发提升。
优点：手感爽快，追击和转场快。
缺点：操作要求高，容错较低。
使用场景：高机动目标、远程后排多的波次。
前置角色：`wind` 拉怪成团便于连跳贯穿。
后置角色：`vampire` 或 `executioner` 收低血。
示例连招：Q布锚 -> E追位 -> F超载连跳把后排一口气切穿。

### 套件16 血契换伤（Q16+E06+F08）
玩法表现：消耗生命换节奏，风险收益玩法。
Q非闭合：按长度扣血，线伤显著提升。
Q闭合：血契场持续吸血回本并压场。
E作用：资源置换，血/能互换救节奏。
F作用：资源狂热，短时间高频施法。
优点：爆发窗口强，能打逆风。
缺点：血线管理难，误操作惩罚大。
使用场景：中后期资源紧张、要强行抢节奏时。
前置角色：`medic`、`banner` 先给生存保障。
后置角色：`pyro`、`necro` 把窗口伤害吃满。
示例连招：Q压血换伤 -> E置换补能 -> F狂热连发抢回战场主动权。

### 套件17 相位错杀（Q17+E05+F06）
玩法表现：穿透、错位、回放，制造“打不到你”。
Q非闭合：短时穿怪，敌人延迟受伤。
Q闭合：闭合区敌人被随机错位，阵型崩解。
E作用：相位换位，和关键目标互换位置。
F作用：时序回放，补足错位期间累计伤害。
优点：生存和进攻一体，玩法新鲜。
缺点：对新手不直观，练习成本高。
使用场景：高威胁后排怪、冲锋怪混编。
前置角色：`jailer` 先短控关键单位。
后置角色：`gambler`、`hunter` 打错位后的单点。
示例连招：Q错位打乱 -> E换到后排位 -> F回放把延迟伤害一次性结算。

### 套件18 雷链清屏（Q18+E16+F15）
玩法表现：链式导电，越聚越强。
Q非闭合：线段命中触发单跳链。
Q闭合：雷网高频跳链，附带微击退。
E作用：雷磁标定，锁定优先跳链目标。
F作用：连锁雷狱，全场导电目标持续受雷罚。
优点：群怪效率高，视觉反馈强。
缺点：对单体Boss时需要其他技能补伤。
使用场景：大量轻中甲小怪波。
前置角色：`wind` 或 `herder` 先聚怪。
后置角色：`executioner` 收精英残血。
示例连招：Q闭合成雷网 -> E标定精英 -> F雷狱同时清杂与磨精英。

### 套件19 毒带驱赶（Q19+E10+F21）
玩法表现：线外更痛，逼怪走位。
Q非闭合：线两侧毒带持续腐蚀。
Q闭合：圈内相对安全，圈外高毒浪推进。
E作用：凝滞注射，补减速和短定身。
F作用：毒潮迁移，把毒区整体平移压场。
优点：地图控制感强，适合风筝。
缺点：瞬时爆发较弱。
使用场景：跑图战、拖怪战、持久战。
前置角色：`herder` 把怪赶向毒带外沿。
后置角色：`vampire`、`plague` 补持续伤害。
示例连招：Q拉毒带 -> E注射定住边缘怪 -> F迁移毒潮碾过去。

### 套件20 影门纠缠（Q20+E17+F26）
玩法表现：门式控制，敌人越穿越亏。
Q非闭合：穿门生成追击影子。
Q闭合：门墙迷宫，低血目标会被影缚。
E作用：诱导信标，强行让怪去穿门。
F作用：渗透崩解，对受控目标做比例伤害。

使用场景：近战怪密集、通道型地形。
前置角色：`glacier` 先封路迫使怪绕门。
后置角色：`executioner` 处决影缚目标。
示例连招：Q摆门阵 -> E信标诱导穿门 -> F崩解统一收割。

### 套件21 重力围井（Q21+E23+F13）
玩法表现：可推可拉，闭合成井。
Q非闭合：按画线方向打推拉脉冲。
Q闭合：形成向心重力井持续聚怪。
E作用：过载充能，缩Q冷却保持控场不断档。
F作用：牵引风暴，移动核心二次聚怪。
优点：团队适配度高，几乎可配任何AOE。
缺点：自身单次爆发不高。
使用场景：任何需要稳定聚怪的构筑。
前置角色：`wind` 或 `butcher` 做第一次聚怪。
后置角色：`pyro`、`tesla`、`sapper` 吃满AOE。
示例连招：Q闭合开井 -> E回能续Q -> F风暴移动聚怪，队友全屏清理。

### 套件22 折镜炮廊（Q22+E18+F31）
玩法表现：弹道折射加回音反击。
Q非闭合：投射物穿线折射覆盖扇面。
Q闭合：闭合区复制投射物一次。
E作用：断后烟幕，保证炮廊期间生存。
F作用：回音交响，分批释放缓存波峰。
优点：弹幕队上限极高。
缺点：依赖武器和弹道数量。
使用场景：远程主C、持续火力阵容。
前置角色：`ammo`、`hunter` 先堆弹量。
后置角色：`new_tempest` 补范围雷击。

### 套件23 拒马封路（Q23+E28+F04）

示例连招：Q封路 -> E压制圈重叠 -> F禁行，怪群只能挨打。

### 套件24 旋刃绞盘（Q24+E19+F27）

使用场景：中甲群怪、围殴波。

后置角色：`executioner` 斩杀收尾。

### 套件25 晶柱共振（Q25+E09+F01）

后置角色：`tesla` 补雷链扩散。
示例连招：Q先摆晶柱 -> E过载提频 -> F重布二次共振炸场。

### 套件26 诱饵控潮（Q26+E08+F07）
