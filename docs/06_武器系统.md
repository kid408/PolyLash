# 武器系统 (WeaponConfigLoader)

## 系统概述

武器系统负责从优化后的 CSV 配置文件加载武器数据，并通过等级倍率系统动态生成 WeaponStats 对象。

**核心特点**:
- 每武器1行配置（大幅减少维护成本）
- 等级倍率系统（自动计算等级属性）
- 动态生成 WeaponStats
- 支持模板路径（贴图、图标）
- 缓存机制（提高性能）

## 等级倍率系统

### 计算公式

#### 伤害
```
Final_Damage = base_damage + (base_damage * damage_scale * (level - 1))
```

**示例**:
```
base_damage = 10
damage_scale = 0.5  # 每级 +50%
level = 3

Final_Damage = 10 + (10 * 0.5 * 2) = 10 + 10 = 20
```

#### 冷却时间
```
Final_Cooldown = max(0.1, base_cooldown + (cooldown_scale * (level - 1)))
```

**示例**:
```
base_cooldown = 1.0
cooldown_scale = -0.1  # 每级 -0.1秒
level = 3

Final_Cooldown = max(0.1, 1.0 + (-0.1 * 2)) = 0.8
```

#### 射程
```
Final_Range = base_max_range + (range_scale * (level - 1))
```

**示例**:
```
base_max_range = 150
range_scale = 10  # 每级 +10
level = 3

Final_Range = 150 + (10 * 2) = 170
```

#### 暴击率
```
Final_Crit_Chance = base_crit_chance + (0.01 * (level - 1))
```

**固定增长**: 每级 +1%

## 核心API

### 获取武器 Stats
```gdscript
func get_weapon_stats(weapon_id: String) -> WeaponStats
```

**参数格式**:
- `"base_id_level"`: 如 `"punch_1"`, `"laser_3"`
- `"base_id"`: 如 `"punch"`（默认等级1）

**返回值**: WeaponStats 对象（包含所有计算后的属性）

**示例**:
```gdscript
# 获取拳头 Lv.3 的 Stats
var stats = WeaponConfigLoader.get_weapon_stats("punch_3")
print("伤害: ", stats.damage)
print("冷却: ", stats.cooldown)
print("射程: ", stats.max_range)

# 获取拳头 Lv.1 的 Stats（默认等级）
var stats_lv1 = WeaponConfigLoader.get_weapon_stats("punch")
```

### 获取武器信息
```gdscript
func get_weapon_info(weapon_id: String) -> Dictionary
```

**返回字典**:
```gdscript
{
    "weapon_id": "punch_3",
    "base_id": "punch",
    "display_name": "拳头 Lv.3",
    "type": "melee",
    "level": 3,
    "max_level": 4,
    "icon_path": "res://assets/sprites/weapons/weapon_punch_3.png",
    "upgrade_to": "punch_4",  # 下一级武器ID（满级时为空）
    "item_cost": 3  # 花费 = base_cost * level
}
```

**用途**:
- UI 显示武器信息
- 武器升级系统
- 商店物品生成

### 获取所有武器ID
```gdscript
func get_all_weapon_ids() -> Array
```

**返回**: 所有武器的 base_id 数组

**示例**:
```gdscript
var all_weapons = WeaponConfigLoader.get_all_weapon_ids()
# 返回: ["punch", "laser", "shotgun", "heal_bolt", ...]
```

### 清除缓存
```gdscript
func clear_cache() -> void
```

**用途**: 热重载配置时清除缓存

## 缓存机制

### 缓存策略
- 首次加载时创建 WeaponStats 并缓存
- 后续访问直接返回缓存对象
- 使用 `weapon_id` 作为缓存键

### 缓存键格式
```
"base_id_level"  # 如 "punch_3"
```

### 清除缓存
```gdscript
WeaponConfigLoader.clear_cache()
```

**使用场景**:
- 热重载配置文件
- 调试武器属性
- 内存优化

## 使用示例

### 1. 创建武器实例
```gdscript
# 在 PlayerBase 中装备武器
func equip_weapon(weapon_id: String) -> void:
    var stats = WeaponConfigLoader.get_weapon_stats(weapon_id)
    if not stats:
        printerr("无法加载武器: ", weapon_id)
        return
    
    # 创建武器场景
    var weapon_scene = load(stats.base_scene_path)
    var weapon = weapon_scene.instantiate()
    
    # 应用 Stats
    weapon.apply_stats(stats)
    
    # 添加到角色
    add_child(weapon)
```

### 2. 武器升级
```gdscript
func upgrade_weapon(current_weapon_id: String) -> String:
    var info = WeaponConfigLoader.get_weapon_info(current_weapon_id)
    var next_weapon_id = info.get("upgrade_to", "")
    
    if next_weapon_id.is_empty():
        print("武器已满级")
        return current_weapon_id
    
    # 检查花费
    var cost = info.get("item_cost", 0)
    if DataManager.get_total_gold() < cost:
        print("金币不足")
        return current_weapon_id
    
    # 扣除金币
    DataManager.add_gold(-cost)
    
    # 装备新武器
    equip_weapon(next_weapon_id)
    
    return next_weapon_id
```

### 3. 显示武器信息
```gdscript
func display_weapon_info(weapon_id: String) -> void:
    var info = WeaponConfigLoader.get_weapon_info(weapon_id)
    var stats = WeaponConfigLoader.get_weapon_stats(weapon_id)
    
    print("武器名称: ", info.display_name)
    print("等级: ", info.level, "/", info.max_level)
    print("伤害: ", stats.damage)
    print("冷却: ", stats.cooldown, "秒")
    print("射程: ", stats.max_range)
    
    if not info.upgrade_to.is_empty():
        print("升级花费: ", info.item_cost, " 金币")
```

## 常见问题

### Q1: 为什么武器属性没有正确缩放？
**检查清单**:
1. 确认 CSV 中的倍率字段（damage_scale, cooldown_scale 等）
2. 检查等级是否正确传入
3. 验证计算公式是否正确

### Q2: 如何添加新武器？
**步骤**:
1. 在 `weapon_config_optimized.csv` 中添加一行
2. 设置 base_id, 基础属性, 倍率
3. 创建对应的武器场景和贴图
4. 重启游戏加载配置

### Q3: 如何修改武器等级上限？
**步骤**:
1. 修改 CSV 中的 `max_level` 字段
2. 确保有足够的贴图资源（如果使用模板）
3. 重启游戏

### Q4: 贴图模板不生效？
**检查清单**:
1. 确认模板格式包含 `%d`
2. 检查贴图文件是否存在
3. 验证路径是否正确

## 最佳实践

### 1. 倍率设计原则
- 伤害倍率: 0.3-0.6（每级 +30%-60%）
- 冷却倍率: -0.1 到 -0.2（每级减少 0.1-0.2秒）
- 射程倍率: 5-20（每级增加 5-20）

### 2. 等级平衡
- Lv.1: 基础属性
- Lv.2: +50% 伤害
- Lv.3: +100% 伤害
- Lv.4: +150% 伤害 + 特殊效果

### 3. 性能优化
- 使用缓存避免重复创建 Stats
- 只在需要时加载武器场景
- 预加载常用武器

### 4. 配置维护
- 使用模板路径减少重复
- 统一命名规范
- 定期检查配置完整性
