# 缚丝（Silk）角色技能实现规格 (Pixel-Level V2)

1. 角色设计灵魂 (The Brotato Rule)
一句话签名：“你们的痛苦是相通的。杀一头羊，和屠一座城，对我来说只需要同样的力气。”

物理特权（灵魂锁链）：她的画线可以把多个敌人的“生命线”强行缝合在一起。伤害共享，Debuff 共享！

致命代价（和平主义者）：她自己没有任何直接伤害技能。她的平A伤害极低，她的画线基础伤害为 0。如果只用她一个人在场上，甚至连一只精英怪都打不死。她必须依赖小队切人机制（Tab 键）才能发挥出毁天灭地的作用。

2. 核心连携场景（为什么她能封神？）
想象一下这个顶级操作：

切出【缚丝】，用右键画一条长线，穿过 30 只小怪和 1 只精英怪。它们被一根红色的光纤连在一起（伤害共享）。

切出【坍缩者（狙击手）】，对着那只精英怪画一个 250px 的小圈，触发“黑洞处决（10.0A直伤）”。

结算爆炸：黑洞不仅秒杀了精英怪，通过【缚丝】的灵魂锁链，这 10.0A 的超高单体伤害被 100% 传递给了那 30 只小怪！只用了一次单体技能，全屏瞬间蒸发！

这就叫真正的【协律】！

## 3. 右键技能：因果缝合 (Causal Stitch)

### 3.1 状态 A：开线结算 -> `[soul_link]` 共享链接
- **判定条件**：右键松开时，画线首尾未相交。
- **视觉表现**：被线划过的敌人，身上会出现红色的锁链特效（VFX），彼此之间隐约有红线相连。
- **核心逻辑**：所有与 Area2D 碰撞的 `Enemy`，注入全局唯一的 `[soul_link]` 状态。
- **`[soul_link]` Debuff 属性 (需要 Codex 引入全局伤害总线)**：
  - `duration`: **10.0** 秒。
  - **特权 1 (伤害共享)**：任意一个带有 `[soul_link]` 的敌人受到伤害（Damage_X）时，所有其他带有此状态的敌人，受到等同于 `Damage_X * 0.8` 的真实伤害（即 80% 传递率）。*(注：为防止无限循环死锁，传递产生的伤害不能再次触发传递)*。
  - **特权 2 (状态传染)**：任意一个带有 `[soul_link]` 的敌人被挂载了新的 Modifier（如血役师的 `[寄生]`、焦耳的 `[化危焦油]`），该状态会瞬间无视距离传染给所有链接者！

### 3.2 状态 B：闭合圈结算 -> 收割 (Harvest)
她不能杀人，但她能为全队疯狂回蓝。
- **判定条件**：右键松开时，画线首尾相交。
- **核心逻辑**：
  1. 遍历闭合圈内的所有 `Enemy`。
  2. 提取其中带有 `[soul_link]` 状态的敌人。
  3. **暴力扯断**：立刻调用 `remove_modifier("soul_link")`。
  4. **能量反馈**：每扯断一根链接，为整个小队（含后台角色）恢复 **15** 点能量。
  5. 无任何直接伤害。这鼓励玩家“大范围连线 -> 圈住收割 -> 给大C回蓝 -> 切人放大招”。

## 4. E 技能：命运收束 (Convergence)

- **施法定位**：瞬发全图技能。
- **执行逻辑**：
  1. 瞬间检索全局 (Global) 存活的带有 `[soul_link]` 状态的 `Enemy`。
  2. 计算它们的**几何中心坐标 (Centroid)**。
  3. 将所有被链接的敌人，在 **0.5** 秒内强行拖拽、聚拢到该几何中心点！
  4. **战术意义**：把全屏散落的敌人用红线串起来，然后一个 E 键把它们拉成一坨。切出【焦耳（爆破专家）】画一个圈，一锅端。

---

## 5. F 技能：众生相连 (Web of Destiny)

- **执行逻辑**：
  1. 没有任何伤害。
  2. 释放全屏脉冲（VFX）。
  3. 无视距离、无视屏幕外，瞬间为场上**所有的怪物**挂载 `[soul_link]` 状态，持续时间锁定为 **15.0** 秒。
  4. 并且，在此期间，伤害传递率从 80% 提升至 **150%**！（即打一只怪 100 血，其他所有怪掉 150 血）。
  5. 这是极致的清场前奏。

---

## 6. 后台 Assist 被动：共情光环 (Empathy Aura)

- **触发条件**：前台角色使用右键画出**闭合圈**，并成功造成伤害时触发。
- **内置冷却 (ICD)**：**8.0** 秒。
- **执行逻辑**：
  1. 取前台闭合圈内受到伤害最高的那个敌人。
  2. 系统以该敌人为中心，向外发射 3 根自动寻敌的红线（长度 300px）。
  3. 被红线刺中的 3 名敌人，会被强制挂载 `[soul_link]` 状态 5.0 秒，并立即承受刚才闭合圈的 50% 伤害。
  4. **战术意义**：当【缚丝】在后台时，她能让原本范围较小的主C技能（比如【坍缩者】的小黑洞）获得恐怖的“溅射/溅射链”效果。
