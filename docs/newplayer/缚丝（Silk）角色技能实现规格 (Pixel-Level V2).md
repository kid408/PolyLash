# 缚丝（Silk）角色技能实现规格（Pixel-Level V2）

## 当前正式实现

- 正式角色 ID：`silk`
- 正式输入：`右键` 画线，`左键` Dash，`E` 能量回流，`F` 众生相连

## Space：因果缝合

### 开线结算

- 右键开放线会给路径扫过的敌人挂上 `[soul_link]`。
- 链接目标仍然保留共享伤害与共享异常的正式链路。

### 闭合圈结算

- 若画出闭合区域，会对圈内已链接目标执行 `Harvest`：
  - 清除链接
  - 每根链接为全队恢复 `15` 点能量

## E：能量回流

- 消耗：`25`
- 冷却：`10.0 s`
- 这是本轮重做后的正式版本，不再把所有已链接目标拖到几何中心。
- 当前结算逻辑：
  - 检索全场所有带 `[soul_link]` 的目标
  - 逐个扯断链接
  - 每根被扯断的链接造成一次 `60` 点真实伤害
  - 伤害结算后立刻清空该目标的链接标记

## F：众生相连

- 保持正式实现不变：
  - 全场挂链
  - 持续强化链接传播
  - 服务于切人和连携爆发

## 本轮调整摘要

- `E` 已从“聚怪控制技”正式改成“扯断全场灵魂链接的真伤回收键”。
- 这次重做的目标是给缚丝补一点前期收尾能力，但不让她变成主 C。
- `60` 点真伤足以稳定清掉前期脆皮杂兵，不足以直接抹掉中型和精英目标。
