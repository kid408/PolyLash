# 极简主义者（斩铁）角色技能实现规格 v1

## 1. 角色灵魂与土豆兄弟法则（Brotato Test）

一句话签名：“花哨的轨迹留给弱者，杀人，一条直线就够了。”

体验目标：极致的“居合斩”与瞬杀快感。他把画线游戏玩成了最纯粹的剑道对决。

物理特权（绝对锋刃）：他的线越直、越简单（没有弯折和多边形），附带的物理切割倍率和突进爆发就越恐怖。他能将鼠标画出的笔直轨迹，转化为一道极速延迟斩击的剑气，配合自身的冲刺瞬间引爆战场。

致命代价（一击脱离的钢丝）：他没有大范围的控场圈，也没有复杂的全屏 AOE。他的战斗就是不断地在怪群中穿插、拉扯，寻找那条能一次性串联最多敌人的“致命直线”。一旦冲刺（Dash）的位置失误，或者画线被地形卡住，他极度脆弱的近战身板会瞬间蒸发。

## 1. 文档定位

这是一份 `单角色实现规格文档`。
本文档定义极简主义者（斩铁）在当前版本中的技能逻辑。
本角色具有极高的操作门槛，核心在于“空间规避与长度变现”。开发时必须严格按本文档的动态几何膨胀算法与 Hitstop（帧冻结）规则执行。

## 2. 角色定位

### 2.1 体验目标

1. 玩家左手专注于走位，大拇指控制画线（Space）。
2. 玩法核心是在怪海边缘狂奔拉长线，体验“线越长，剑气越宽，时空静止越久”的极端奖赏。
3. 任何自交都会导致全盘皆输，要求极高的走位规划能力。

### 2.2 玩法签名

`Space 蓄弦 -> 极限规避自交 -> 松开引爆膨胀剑气与定帧 -> E 键震荡残痕保命`

## 3. 统一术语

- `光弦`：玩家按住 Space 键时在地面留下的引导轨迹（无伤害判定）。
- `膨胀剑气`：松开 Space 瞬间，由光弦向两侧等距剧烈膨胀生成的瞬时多边形伤害判定区。
- `熔毁切痕`：剑气爆发后，留在原地持续存在的线性资产。
- `自交断裂`：光弦在绘制过程中与自身发生交叉导致的惩罚状态。
- `定帧 (Hitstop)`：松开长线瞬间，强制暂停全场敌人与投射物物理演算的特殊状态。

## 4. 技能与行动资源规则

### 4.1 Space 键（核心画线）
- 输入方式：`按住 Space 拖动鼠标生成轨迹，松开释放`
- 规划时间倍率：`1.0`（纯即时，无慢动作）
- 采样间距：`10 px`
- 基础画线成本：`每 10 px 消耗 0.4`
- 闭合逻辑：**绝对禁止闭合**。一律按开放线段处理。

### 4.2 冲刺（Dash）
- 消耗/位移：`5 能量 / 400 px`
- 无敌帧：`0.35 s`
- 专属联动：Dash 无敌帧期间，**暂时关闭自交检测**，允许光弦穿插越过自身。

## 5. Space 技能：光弦拔刀

### 5.1 蓄弦态（绘制阶段）

- 玩家按住 `Space` 键，跟随鼠标生成光弦。
- 每一帧，新生成的线段必须与当前所有已存在的光弦线段执行 `交叉检测 (Segment Intersection)`。
- **自交断裂处理**：若玩家**不在 dash 无敌帧内**且发生线段交叉：
  1. 立即强制中断蓄弦态。
  2. 清空当前所有光弦，本次消耗的能量不予退还。
  3. 给予玩家角色 `1.0 s` 的减速惩罚（移速降至 60%）。
  4. 播放碎裂失败音效。

### 5.2 拔刀结算态（松开阶段）

- 只要未发生自交，松开 `Space` 键立即进入拔刀结算。
- 提取本次光弦的总长度 `L` (px)。

### 5.3 膨胀剑气判定（几何与伤害）

参数公式：
- 基础半宽：`20 px`
- 最大额外半宽：`150 px`（在长度 2500 px 时达到上限）
- 基础伤害：`0.80A`

计算本帧生成的膨胀属性：
1. `宽度膨胀系数 = min(L / 2500.0, 1.0)`
2. `实际半宽 = 20 + 宽度膨胀系数 * 150`
3. `最终伤害 = 0.80A * (1.0 + 宽度膨胀系数 * 2.5)`

生成判定区与结算：
1. 沿原始光弦轨迹，向左和向右各法向偏移 `实际半宽`，生成一个巨大的连续多边形（Polygon2D / 复合 CollisionShape）。
2. 对处于多边形内部的所有存活敌方目标造成 `最终伤害`。

### 5.4 定帧结算 (Hitstop)

参数：
- 定帧起步阈值：`L >= 800 px`

定帧执行规则：
1. 若 `L < 800`，不触发定帧。
2. 若 `L >= 800`，计算 `定帧时长 = 0.2 + min((L - 800) / 1700.0, 1.0) * 1.0`。
3. 在拔刀当帧，**暂停场景内所有敌人的物理移动、动画与行为树**，持续对应的 `定帧时长`。
4. 玩家角色不受定帧影响。

### 5.5 资产留存：熔毁切痕

- 拔刀结算完成后，在原始光弦的路径上生成无碰撞体积的 `熔毁切痕`。
- 带有 `[高热]` 与 `[金属]` 逻辑标签。
- 持续时间：`4.0 s`，随后自动销毁。场上最多存在 1 条切痕，生成新切痕时旧切痕立刻销毁。

## 6. E 技能：弦音共振

利用地上的切痕资产，进行大范围击退保命。

### 6.1 释放与结算

参数：
- 消耗与冷却：`40 能量` / `8.0 s CD`
- 震波半宽：`80 px`
- 击退距离：`180 px`
- 震荡伤害：`0.45A`

执行逻辑：
1. 检索场上唯一的 `熔毁切痕`。若不存在，进 CD 并播 MISS。
2. 若存在，以该切痕为中轴，瞬间生成半宽 `80 px` 的震波判定区。
3. 对区域内所有敌人造成 `0.45A` 伤害。
4. 施加击退：计算目标到切痕最近点的法线向量（由切痕指向目标），沿该向量对目标施加 `180 px` 的击退位移（遇静态墙体停止）。

## 7. F 技能：维度断裂

沿着自己画出的最长轨迹进行光速穿梭斩击。

### 7.1 释放与结算

执行逻辑：
1. 扣除 `40% 能量`。检索当前场上的 `熔毁切痕`。若无切痕，技能释放失败，全额退还能量。
2. 若有切痕，玩家角色瞬间进入无敌态。
3. 沿切痕路径，每隔 `60 px` 瞬间生成一个半径 `100 px` 的爆炸圆判定。
4. 每个爆炸圆对区域内敌人造成 `2.50A` 的真实伤害（允许重叠叠加伤害）。
5. 表现持续 `0.4 s` 后，玩家角色强制传送到切痕的**终点位置**。
6. 旧切痕立刻销毁。

## 7.1.0. 斩铁后台被动：笔触校准

### 7.1.1 触发机制

- **触发条件**：前台角色松开 `Space` 键完成一次开放线绘制当帧。
- **几何与冷却**：
  - 直线检定：计算 `(光弦起点到终点的直线距离) / (光弦实际轨迹的总长度)`。若比值 `>= 0.9`，判定为近似直线。
  - 内置 CD：`3.0 s`。

### 7.1.2 物理与状态结算

1. **能量返还**：向玩家能量池返还本次画线消耗的 `20%`，但单次返还量**硬性封顶为 `5` 点能量**。
2. **视觉提示**：沿绘制的直线路径，播放一次快速闪过的微光特效（不附带任何破甲或额外伤害判定）。

## 8. 验收边界规范

1. **自交熔断**：只要画线交叉，不管线有多长，立刻断裂且不产生任何伤害。
2. **Dash 容错**：在 Dash 进行期间强制关闭交叉检测算法，确保玩家能“跳过”自己的线。
3. **定帧全局性**：Hitstop 必须对整个 Enemy 层生效（通过暂停节点的 Process 或动画控制），确保视觉上的时间静止感。
4. **多边形重叠绞杀**：如果玩家画了一个 U 型，向两侧膨胀的剑气在 U 型内部发生重叠，系统必须正确处理该多边形的闭包，或者允许重叠部分造成一次标准伤害（无需多段伤害，确保单次判定覆盖整个内部区域即可）。
