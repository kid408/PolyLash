# 方阵（Phalanx）角色技能实现规格 (Pixel-Level V2.5)

## 1. 角色灵魂与土豆兄弟法则（Brotato Test）
- **一句话签名**：“你冲得越猛，你的骨头砸在同伴身上时就越碎。”
- **体验目标**：极致的“弹球/保龄球”物理碰撞快感。通过画出不同角度的偏导墙，把敌人变成炮弹，并在闭合区间内打造疯狂的弹球机。
- **物理特权（动能反弹与回收）**：线是一面“斥力屏障”，不仅能反弹敌人，还能像除雪车一样将屏障收回，强行清空路径。
- **致命代价（极度脆皮的墙）**：墙不是绝对无敌的掩体，而是受长度制约的消耗品。耐久耗尽墙体会碎裂。玩家无法画圈无限挂机，必须不断移动并计算反弹几何角度。

## 4. 右键技能：矢量偏导 (Vector Deflection)

### 4.1 状态 A：开线结算 -> [斥力屏障] (动能蹦床)
- **执行逻辑**：生成一面蓝色的 `[斥力屏障]`，存活 **8.0** 秒。
- **耐久度算法**：最大反弹次数 = `Max(2, int(L / 40))`。
- **动能反弹触发 (Bounce)**：
  - 怪物触碰屏障，扣除 1 耐久度。
  - 怪物受 0 点伤害，打断当前动作。沿屏障法线方向以 **1200px/s** 的速度被击退抛飞（最大抛飞距离 150px），挂载 `[肉体炮弹]` 状态。
- **保龄球连带结算**：
  - 处于 `[肉体炮弹]` 状态的怪物若撞到其他怪物：双方同时受到 `1.0 * PlayerBase_ATK` 的物理伤害。被撞者轻微后仰 10px。随后 `[肉体炮弹]` 状态解除。

### 4.2 状态 B：闭合圈结算 -> [动能弹球机] (Pinball Arena)
- **执行逻辑**：画出闭合围墙，拥有极高耐久度，存活 **4.0** 秒。
- **耐久度算法**：最大反弹次数 = `Max(2, int(L / 40))`。
- **弹球机机制**：
  - 圈内敌人被赋予初始动能，以 **1500px/s** 极速在圈内来回反弹。
  - 每次撞击内壁或互相碰撞，受到 `1.0 * PlayerBase_ATK` 伤害。
- **复位兜底 (核心防呆)**：
  - **当 4.0 秒结束围墙炸裂消失时，系统强制清空所有被弹射敌人的惯性动能。所有内部敌人瞬间停止飞行，落地并回归正常的寻路移动 AI。**

## 5. E 技能：动能开球

- **执行逻辑**：
  1. 瞬间施法。检索场上所有方阵的未闭合 `[斥力屏障]`。
  2. 每一面屏障瞬间锁定其背离玩家的法线方向（即向外/向前），以 2000px/s 的极速，像巨型台球杆一样向前平移冲刺 800px！
  3. 大力开球判定：平移过程中碰到的所有敌人，被赋予 [重型肉体炮弹] 状态，并跟随屏障一起向深处被强制抛飞（最远抛飞 800px）！
  4. 毁灭撞击：由于抛飞距离极远且速度极快，这些“母球”必将砸穿后排的怪群。飞行中的母球每撞到一个其他敌人，都会引发一次 3.5 * PlayerBase_ATK 的保龄球爆炸伤害，并在冲刺 800px 结束后，屏障自动销毁。

## 6. F 技能：绝对刚体 (Absolute Rigid Body)

- **执行逻辑**：
  1. 进入 **6.0 秒**的“动能过载”模式。场上所有 `[斥力屏障]` 耐久度变为无限。
  2. **肉身反弹特权**：方阵本体化为屏障。
  3. **体型判定 (Boss 防护)**：
     - **普通/精英怪**靠近：自动被弹飞并变成 `[肉体炮弹]` (冷却 0.5s/怪)。
     - **Boss级别敌人**靠近或攻击玩家：**免疫弹射和位移**。Boss 仅受到一次 `3.0 * PlayerBase_ATK` 的反噬伤害，动作不被打断，维持 Boss 战的压迫感。

## 7. 后台 Assist 被动：反应装甲 (Reactive Armor)

- **触发条件**：前台角色受到攻击即将掉血时触发（CD 15.0s）。
- **执行逻辑**：抵消该次伤害（免疫1次）。前台角色爆开斥力波，将攻击者强制弹开 50px。不附带伤害和炮弹状态，纯防御机制。
