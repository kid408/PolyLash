# 弧光（Arc）角色技能实现规格

## 当前正式实现

- 正式角色 ID：`arc`
- 正式输入：`右键` 画线并进入穿梭，`左键` Dash，`E` 紧急漂移起爆，`F` 矩阵超频

## Space：量子折跃

### 开线与闭合

- 保持当前正式版本：
  - 开放线进入高速穿梭
  - 闭合线进入离心绕圈
  - 自交成环仍然视作闭合成立

### 本轮生存规则重构

- 旧版“穿梭期间绝对无敌”已废除。
- 新版正式规则改为：
  - `Dash` 无敌仍然保留
  - `穿梭 / 漂移` 期间仅获得 `霸体`
  - `穿梭 / 漂移` 期间承受伤害乘区变为 `20%`，即等价于 `80%` 减伤
  - `穿梭 / 漂移` 期间忽略自身击退

### 打断规则

- 穿梭过程中若撞到以下目标，会立刻中断：
  - 精英敌人
  - Boss
  - `StaticBody2D` 墙体
- 被打断后：
  - 立即退出穿梭
  - 自身进入 `0.5 s` 硬直眩晕

## 本轮调整摘要

- 这次不是单纯削弱，而是把弧光从“无脑绝对安全”改回“高机动高风险”。
- 现在他仍然能高速切阵，但终点、路径和碰撞对象都必须认真规划。
