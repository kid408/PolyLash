# 坍缩者（点阵狙击手）角色技能实现规格 v1

## 当前正式实现

- 正式角色 ID：`collapse`
- 正式输入：`右键` 绘制光弦，`左键` Dash，`E` 重力井，`F` 事件视界
- 画线长度上限：`360 px`
- 闭合判定阈值：`56 px`
- 右键基础消耗：`10` 能量

## Space：奇点坍缩

### 开线阶段

- 按住 `右键` 采样绘制，采样间距 `10 px`。
- 若总长度超过 `360 px`，立刻触发 `SHORT` 短路失败，清空本次轨迹，不触发任何伤害。
- 允许自交；自交点会被视为闭合成立。

### 松手结算

- 未闭合：判定为 `WASTE`，纯浪费一次画线成本，不生成任何场资产。
- 成功闭合：在闭合区域几何中心生成一个持续型 `奇点陷阱`。

### 奇点陷阱

- 存活时间：`3.5 s`
- 牵引半径：`140 px`
- 牵引强度：`620 px/s`
- 伤害结算间隔：`1.0 s`
- 每次结算都会重新统计圈内敌人数，并动态缩放单体倍率：
  - `1` 个目标时：`3.0A`
  - `5` 个及以上目标时：`0.5A`
  - `2-4` 个目标在线性衰减区间内
- 设计意图：少量目标高收益，乱框怪海收益显著降温。

## E：重力井

- 消耗：`30`
- 冷却：`6.0 s`
- 以鼠标点为中心，瞬间牵引 `250 px` 内敌人，并附加短时强减速。
- 该技能本身不负责爆发，主要用于给小闭环做局、压缩怪群位置。

## F：事件视界

- 消耗：当前能量的 `40%`
- 若场上没有存活奇点，则释放失败并退款。
- 若场上存在奇点，则所有奇点一起膨胀为 `事件视界`：
  - 半径：`300 px`
  - 持续：`3.0 s`
  - 持续牵引
  - 每 `0.2 s` 造成一次 `1.5A` 真伤
  - 结束时追加一次 `5.0A` 真伤终爆

## 本轮调整摘要

- 闭合判定阈值从更苛刻的小值放宽到 `56 px`，降低微雕难度。
- 旧版“触发即吞噬的单次陷阱”已经改成“可留场的持续牵引奇点”。
- 奇点伤害现在按圈内敌人数动态缩放，前期手感更顺，但不会因为乱框怪海而过强。
