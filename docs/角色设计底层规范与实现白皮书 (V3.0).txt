第一部分：绝对核心原则 (The Golden Rules)
任何新角色的设计，在构思机制之前，必须绝对服从以下三大引擎和交互底线：

1. 物理输入不可违背 (SpaceSkill 框架)
动作唯一性：角色的核心动作必须且只能是“按住右键拖拽画线，松开右键结算闭合”。

禁止魔改输入：严禁设计出“单击右键发射子弹”、“右键变成射抓钩”等脱离 hold_and_trace（拖拽绘制）和 line_and_polygon（线段与多边形判定）底层代码的机制。

2. 战斗频率金字塔 (Combat Frequency Pyramid)
角色的技能定位必须严格遵循以下使用频率和能量依赖关系：

▶ 鼠标右键 - 未闭合画线 (最高频 / 核心平A)：消耗能量的主力输出或战场铺设手段。决定了角色的基础操作手感（如：斩铁的切割、方阵的推墙、溶媒的涂地）。

▶ 鼠标右键 - 闭合圈 (中高频 / 进阶爆发)：消耗能量的进阶手段。通常用于对群终结、机制引爆或防守反击。

▶ E 键技能 (低频 / 战术小技能)：受冷却时间（CD）限制。绝不能作为常规平A循环的一环，必须定位为“救命底牌”、“关键位移”或“打破僵局的强制引爆器”。

▶ F 键技能 (极低频 / 终极大招)：受长冷却时间（CD）限制。用于瞬间改变战场规则或全屏清场。

▶ Q 键技能 - 战术拒止 (中低频 / 通用防身)：全角色自带的通用击退/清弹幕技能（耗能 15，CD 4s）。设计新角色时将其作为默认的生存底牌，避免 E/F 技能与其同质化。

3. 能量即命脉 (Energy Economy)
画线必须受到能量制约。角色的操作上限往往由其“能量获取与消耗”的闭环决定（如：高耗能的推土机、低耗能的风筝流、以战养战的吸血流）。

第二部分：四大原生职业定位红线 (Mastery Classes)
我们不使用传统的“战、法、牧、刺”，而是基于“画线/闭合”物理法则衍生出的四大原生职能。设计新角色时，必须严格对号入座：

【锋芒】 (The Edge) - 物理切割 / 动能爆发

定位：撕裂怪海的尖刀。机动性极高。

特征：利用画线进行直接、暴力的物理切割。

代表：斩铁（线越长伤害越高）。

【术理】 (The Logic) - 法则掌控 / 状态畸变

定位：改变战场的施法者。

特征：画线本身直伤低，主打挂载异常状态（DoT、减速、易伤），再通过闭合圈触发化学反应/物理塌缩。

代表：焦耳（焦油引爆）、坍缩（黑洞吸附）。

【御阵】 (The Formation) - 空间建筑 / 阵地防线

定位：掌控地形的防御者。

特征：线条具有“实体碰撞/反弹/阻挡”属性。闭合圈用于创造绝对安全区或困兽斗兽场。

代表：方阵（动能弹球机）。

【协律】 (The Harmony) - 状态连结 / 机制共鸣

定位：机制连接者与网络构建者。

特征：在怪物间建立联系，实现伤害传导、团队增益，或者打出特定的节奏连击。

代表：缚丝（灵魂伤害共享）、泛音（琴弦战鼓节奏）。

第三部分：角色设计标准文档模块 (The Standard Template)
以后我为你生成的每一个新角色，都必须包含以下 7 个标准模块（缺失任何一个打回重做）：

模块 1：灵魂与土豆兄弟法则 (Brotato Test)
一句话签名：高度概括角色玩法的 Slogan。

体验目标：玩家玩这个角色时，应该获得怎样的“心流”或“爽点”？

物理特权：他在哪一项规则上拥有全游戏独一无二的优待？（例如：反弹一切、伤害传导）。

致命代价：为了获得特权，他在哪一方面是个残疾人？（例如：极度笨重、不能闭合、没有直伤）。

模块 2：字典与羁绊定义 (Dictionary)
确定内部 player_id。

确定 3x3x3 矩阵定位：[身世 Origin] x [职能 Mastery] x [战术 Tactic]。

确定基础面值：base_speed（200 为标准锚点）与 max_energy。

模块 3：鼠标右键 - 未闭合 (Open Line Mechanics)
详细描述画线时的状态（耗能速度、线条粗细、存留时间）。

明确判定机制：是造成直伤？挂载标记？生成实体墙？还是铺设陷阱？

模块 4：鼠标右键 - 闭合 (Closed Polygon Mechanics)
详细描述闭合成功瞬间的触发逻辑。

明确互动关系：闭合圈是造成直接的面积爆炸？还是与“未闭合”留下的机制产生化学反应（例如引爆DoT、收割印记）？

模块 5：E 技能与 F 技能 (Active & Ultimate)
明确这是受 CD 限制的技能。

E技能：必须设计为解场、自保或战术辅助。

F技能：必须具有大招的视觉表现和数值强度，能够救场。

模块 6：Assist 技能 (后台被动)
角色在后台时，给前台角色提供的被动援助效果（如：替挡致命伤、提供反伤等）。

第四部分：数值与底层代码防坑指南 (Precautions)
设计和调优时，必须在脑海中挂载这四个底层的“防崩坏预警器”：

闭合圈面积陷阱：绝对不能直接将多边形面积 (area) 作为伤害乘区。必须使用开平方 (sqrt(area / PI)) 降维成等效半径，防止伤害指数级爆炸。

无限死循环陷阱：在设计【协律】职业的“伤害传导/反弹”时，必须在代码逻辑中加上 is_shared_damage = true 的布尔值拦截，防止 A 传 B、B 传 A 导致引擎瞬间卡死崩溃。

长线收益倒挂陷阱：如果角色特性鼓励画长线，能量消耗必须有 clamp 硬上限封顶，而伤害增益必须远高于耗能，否则玩家会陷入“越努力越亏”的数值泥潭。

基准移速锚点：永远记住玩家的标准基速是 200。精英怪的速度不应超过 195，疯狗怪在 220 左右，Boss 在 150 左右。角色的 base_speed 设定直接决定了他遛怪的容错率。

操作空间：设计角色时需要考虑到技能应该具有极高微操走位空间，**鼠标右键（画线/闭合）和鼠标左键（Dash冲刺）*的联动，应该能够顶起完整的伤害输出或核心机制流转。仅靠这两个键的组合与走位，就应该能应付绝大多数的关卡施压。
