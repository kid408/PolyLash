# 四项问题排查与待确认信息文档

本文用于整理当前四类核心问题的现象判断、风险来源与后续必须补充的关键信息。
目标不是直接下最终结论，而是为后续数值整改、机制重写与实机验收提供统一的问题框架。

## 1. 方阵（Phalanx）：闭合弹球机秒杀 Boss 的问题

### 现象分析

文档设定中，闭合圈内敌人会被赋予 `1500px/s` 的高速位移，并且每次撞击都会受到 `1.0 * PlayerBase_ATK` 的伤害。

如果 Boss 的碰撞体积较大，而玩家又能在 Boss 脚下画出一个极小闭合圈，那么 Boss 会在极短时间内与闭合圈内壁发生高频碰撞结算。
一旦系统没有足够的碰撞冷却、受击最短间隔或单帧结算限制，就会出现一秒内多次甚至几十次重复伤害，导致瞬间秒杀。

### 风险判断

- 风险核心不在于“单次撞击伤害过高”，而在于“高频重复结算”。
- 极小闭合圈会把“几何收益”错误转化为“帧级重复伤害收益”。
- 如果 Boss 没有专门的弹球受击节流机制，闭合圈将天然对大体型目标产生异常压制。

### 需要你提供的信息

- Boss 碰撞与受击机制：Boss 在受到弹球碰撞伤害时，是否存在最短受击间隔、无敌帧或局部伤害 CD。
- 物理引擎检测频率：当前碰撞检测或物理更新的 Tick Rate 是多少。
- 最小闭合面积限制：系统是否允许玩家画出几乎零面积、仅包裹目标碰撞体的闭合圈。

## 2. 缚丝（Silk）：闭合圈鸡肋与缺乏上链手段

### 现象分析

缚丝当前的核心收益来自 `soul_link` 链接网络。
玩家通过画线给目标挂链后，可以利用共享伤害与后续联动形成高价值的群伤放大。

但现有设计中，闭合圈结算会直接清除所有链接，仅换取每根链接 `15` 点能量回复。
这会导致一个非常反直觉的体验：

- 玩家前面通过开线好不容易建立了核心输出网络。
- 闭合圈一画，却把这套网络直接掐断。
- 最终换到的只是相对有限的能量收益。

与此同时，E 技能也会扯断链接，造成 `60` 点真实伤害并清空标记。
如果 Q 闭合与 E 都以“清空链接”为结算方式，那么缚丝就很容易从“群伤放大器”退化成“不断自拆网络的角色”。

### 风险判断

- 问题核心不是闭合圈数值低，而是它与角色主幻想冲突。
- 如果闭合与 E 都承担“清链结算”，那么玩家会倾向于避免使用它们，或者只把它们当保底键。
- 缚丝一旦缺少稳定、低成本的补链手段，清链类技能的负反馈会进一步放大。

### 需要你提供的信息

- 伤害共享机制：`soul_link` 当前传递伤害的具体比例是多少，传递伤害是否能触发其他角色的被动或联动逻辑。
- 队伍能量缺口：你希望缚丝在队伍中更偏向“充能宝”还是“群伤放大器”，全队对这 `15` 点能量的依赖度有多高。
- 普通攻击与其他技能：除了右键画线和 F 技能“众生相连”之外，缚丝是否还有其他低成本、稳定的小技能或普攻手段可以挂链。

## 3. 斩铁（Minimalist）：能量消耗与收益不成正比

### 现象分析

当前设计中，斩铁的长线超过 `800px` 后会触发更明显的范围压迫与定帧表现。
但如果长度没有同步转化为足够明确的伤害成长，那么玩家就会陷入典型的“高成本低兑现”体验：

- 画得更长。
- 花得更多。
- 视觉更大、定帧更强。
- 但对单体目标的真实击杀效率提升不明显。

再加上斩铁的回能高度依赖右键击杀后返还 `3` 点能量，一旦面对 Boss 或高血量精英，玩家很快就会进入空蓝状态。
这会让角色在“无法快速斩杀”的战斗环境里显得非常迟钝。

### 风险判断

- 问题核心不是“长线没效果”，而是“长线收益没有跑赢长线成本”。
- 如果长线只增加覆盖面，却不显著提高对高价值目标的兑现能力，玩家就不会认为长线值得。
- 斩铁一旦离开击杀回能就迅速熄火，说明资源循环高度依赖顺风场。

### 需要你提供的信息

- 能量消耗公式：斩铁右键画线目前的耗能规则是什么，是否与方阵一样按每 `40px` 扣除 `1` 点能量，或者采用其他换算方式。
- 基础伤害公式：右键画线单次切割的基础伤害倍率或结算公式是什么。
- 当前连击或蓄力机制：系统框架内是否支持根据画线长度、画线时长或其他输入质量，对最终伤害施加线性或非线性系数。

## 4. 敌人（Enemies）：移动速度极化的体验问题

### 现象分析

对于以画线、包围与闭合几何为核心的玩法，敌人移速决定了玩家的操作窗口期。

如果怪物跑得过快，玩家会在闭合前被贴脸、打断或逼迫提前交 dash。
如果怪物跑得过慢，则战场会失去压迫感，画线类角色也更容易把战斗退化为稳定刷图。

因此，敌人移速的平衡目标不是单纯“更快”或“更慢”，而是围绕玩家操作速度构建一个可读、可控、可分层的追击压力系统。

### 风险判断

- 移速问题本质上会直接影响所有画线角色的技能成立率。
- 过快怪会压缩闭合窗口，过慢怪会让战斗丧失动作张力。
- 一旦高压怪与普通怪的速度层级不清楚，玩家会难以形成稳定的预判和应对节奏。

### 需要你提供的信息

- 速度对比基准：方阵的基础移速是 `270`，当前你体感中“太快”和“太慢”的敌人移速大约分别落在多少 `px/s`。
- 画线操作速度：玩家在鼠标或摇杆输入下的画线速度是否存在系统上限，还是主要受输入设备与采样频率影响。

## 补充说明

后续如果要继续推进整改，建议先补齐以下三类信息：

- 受击节流信息：用于判断方阵闭合弹球对 Boss 的极限伤害是否需要强制封顶。
- 资源定位信息：用于判断缚丝到底应优先服务于“回能”还是“放大共享伤害”。
- 成本收益信息：用于判断斩铁长线应强化伤害、强化终结兑现，还是继续回调能量曲线。

在这些信息明确前，任何进一步的数值修改都可能只是在修表象，而不是修根因。
