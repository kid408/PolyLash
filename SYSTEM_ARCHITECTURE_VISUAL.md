## 🔄 数据流向

```
1. 角色选择
   ↓
2. BondManager.recalculate_active_bonds()
   ├─ 统计羁绊标签
   ├─ 检查激活条件
   └─ 存储激活羁绊
   ↓
3. 游戏运行时
   ├─ 技能触发 → 检查 has_mechanic()
   ├─ 属性计算 → apply_stat_modifiers()
   └─ 效果应用 → get_mechanic_value()
   ↓
4. 视觉反馈
   ├─ 浮动文字显示
   ├─ 控制台日志输出
   └─ 特效播放
```
