## 1. 这份文档给谁看

给策划/玩法同学快速看：

不展开代码细节。

## 2. 一键理解：工具做什么

| 工具脚本 | 你能得到什么 |
|---|---|
| `create_character_tool.gd` | 新建一个角色（脚本+角色配置+技能绑定+武器配置+大招配置） |
| `cleanup_csv_tool.gd` | 从角色配置里删掉一个角色（含大招） |
| `assign_character_weapons.gd` | 给当前所有启用角色重新分配可选武器池 |
| `create_enemy_tool.gd` | 新建敌人并加入当前出怪配置链（含导演 v2） |
| `test_enemy_creation.gd` | 自动造 3 个测试敌人检查工具链是否可用 |
| `create_item_tool.gd` | 新建道具/徽章配置 |
| `create_bond_tool.gd` | 新建羁绊（可同时生成对应徽章/圣物） |
| `check_shop_usage.gd` | 检查奖励+商店流程是否缺文件、缺配置、缺 autoload |
| `setup_dual_shop.gd` | 生成当前流程的接入示例脚本（不是旧双商店迁移） |
| `create_weapon_scenes_tool.gd` | 补齐基础武器场景（近战4+远程3） |

---

## 3. 怎么运行

在 Godot 编辑器：
1. 打开 `res://tools/`。  
2. 选中目标脚本。  
3. `File -> Run`。

---

## 4. 常见工作流（策划视角）

## 4.1 新增角色

1. 跑 `create_character_tool.gd`（先把脚本顶部角色参数改好）。  
2. 跑 `assign_character_weapons.gd`（更新角色可选武器池）。  
3. 跑 `check_shop_usage.gd`（确认流程没断）。

---

## 4.2 新增敌人

1. 跑 `create_enemy_tool.gd`。  
2. 去 `wave_units_config_v2.csv` 配波次池（让它真正刷出来）。  
3. 跑 `test_enemy_creation.gd` 快速验证。

---

## 4.3 新增羁绊/道具

1. 羁绊用 `create_bond_tool.gd`。  
2. 道具/徽章用 `create_item_tool.gd`。  
3. 跑 `check_shop_usage.gd` 看商店链路是否正常。

---

## 5. 重要注意事项

1. 这些工具多数会直接改 `config/*.csv`，建议先备份。  
2. `assign_character_weapons.gd` 会重写整张 `player_available_weapons.csv`。  
3. `test_enemy_creation.gd` 会写入测试数据，测完可按需清理。  
4. `setup_dual_shop.gd` 现在是“当前流程校准工具”，不是旧版双商店工具。

---

## 6. 如果你只记一件事

先跑“检查类工具”，再跑“写入类工具”：
1. `check_shop_usage.gd`  
2. 目标写入工具（角色/敌人/道具/羁绊）  
3. 进游戏验证
